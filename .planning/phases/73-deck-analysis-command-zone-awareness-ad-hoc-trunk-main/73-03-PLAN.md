<objective>
Render the command-zone awareness in the prompt text. The enriched `commanderName` (Plan 02) already
flows through the existing `commander:`/`<commander>`/title lines, so partner pairs and Background
already appear after Plan 02. This plan adds the COMPANION field to each of the three variants — three
independent hand-edits per ADR 0001 (`docs/decisions/0001-prompt-variants-decoupled.md`): NO shared
helper, each variant owns its own companion text in its platform-native format.

**Awareness-only, side-metadata only (Codex HIGH-1):** the companion is rendered ONLY in the DECK
CONTEXT block (ChatGPT/Gemini) or as a `<companion>` element (Claude). The deck text is NOT touched.
For Archidekt the companion legitimately stays in the mainboard decklist (`ArchidektApiDeckImporter.cs`
leaves it `mainboard`), so the copy must NOT claim the companion is "outside the 99" or "not in the
deck" — that would be FALSE. The companion line simply NAMES the companion as the deck's companion and
notes its companion deckbuilding restriction; it makes no claim about which zone the card is listed in
(true for both Archidekt, where it is in the 99, and Moxfield, where it is detected separately).

**Injection hardening (Codex HIGH-2):** the value is already single-line-bounded upstream (Plan 02
`BoundCompanionName`). In the Claude variant the value sits inside an XML element, so it MUST be
XML-escaped (`System.Security.SecurityElement.Escape`) to keep a single well-formed `<companion>`
element even for inputs like `</companion>...` or `a & b`. ChatGPT/Gemini render a plain-text
`companion:` line (the prompt is plain text to the AI, not HTML/XML), so the single-line value is
sufficient there — no HTML/XML encoding (and none is wanted, since it would corrupt legitimate names).

Purpose: complete the user-visible awareness — the AI now sees the companion named explicitly.
Output: companion rendering in all 3 variants + per-platform render tests + a deck-text byte-identity
assertion + a malicious-input prompt-shape test. Byte-identical preserved when companionName is null.
</objective>
