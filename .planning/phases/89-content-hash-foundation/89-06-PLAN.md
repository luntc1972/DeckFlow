## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| startup pass → prod/local DB | backfill issues DML (null-only UPDATE) against the web app's DB; must never issue DDL |
| on-disk `.md` → hash | file bytes read + hashed; pure transform |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-89-04 | Elevation/Tampering | backfill running DDL against prod | mitigate | The backfill calls only `SetBodySha256IfNullAsync` (parameterized DML); it contains no DDL. Schema is owned solely by EnsureSchema (D-09). A source grep asserts no ALTER/CREATE in the service. |
| T-89-06 | Tampering | overwriting a good hash | mitigate | Setter is UPDATE ... WHERE body_sha256 IS NULL and the service skips non-null rows before reading — deterministic, idempotent on re-run (D-08). |
| T-89-13 | DoS | startup cost over many rows | accept | One-time single pass over existing rows (hundreds, per the prod audit); one file read + SHA per null row. Bounded, runs once at boot. No new dependency (T-89-SC: SHA256 BCL). |
</threat_model>
