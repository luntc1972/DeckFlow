## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI → content-kb.db / prod Postgres | A destructive DELETE crosses into persistent storage |
| harvested YouTube caption text → stored transcript body | Untrusted external text is embedded (with timestamps) and later fed to the LLM |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-37.5-01 | Tampering / Repudiation | corpus-reset DELETE (CommandRunners.RunCorpusResetAsync) | mitigate | DELETE is scoped to content_videos + content_site_index ONLY (no WHERE-less DELETE of content_sources/blocked_videos); `--dry-run` option lets the operator preview; structured log records deleted row counts for an audit trail; CommandRunnerCorpusResetTests asserts preserved tables are never deleted |
| T-37.5-02 | Elevation of Privilege | prod Postgres reset | accept | Reset is a manual operator-initiated CLI action against an operator-supplied connection; no web endpoint, no automation. Prod execution is gated by the live checkpoint in Plan 03. Local-default path is artifacts/content-kb.db |
| T-37.5-03 | Tampering | timestamped transcript body (YouTubeTranscriptFetcher) | accept | Caption text is stored, not executed; `[mm:ss]` prefix is derived from a trusted TimeSpan, not from caption text. LLM consumption of this text is sandboxed in Plan 02 (`--allowedTools ""`). No new exposure vs. the existing flat-text body |
| T-37.5-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs in this plan — zero new dependencies (verified against CONTEXT/STATE "zero new dependencies" constraint). No legitimacy checkpoint required |
