Finish the semantic-token migration (THEME-01): first capture a pre-migration computed-style baseline
(so 84-02 can prove no-drift), then re-point the three brand-emphasis aliases (--link / --focus /
--cta-border) to var(--accent-strong) so the dominant existing behavior is preserved, then swap ONLY

actual bug fix.

play," which is what lets a red guild's error text (--danger) stop coinciding with its link color
(--accent-strong-derived --link) without a per-guild special case.

~8 already-migrated sites are the only intended color delta (verified visually in Plan 02).
