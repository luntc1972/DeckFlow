<!-- Locked coordinator shape. Grounder is optional (null => grounding skipped, CardGrounded stays null). -->

StatedRulesExtractor (DeckFlow.Core.Knowledge.StatedRulesExtraction):
  ctor(ILlmDistillationService distiller, ICardNameGrounder? cardGrounder = null)
  Task<IReadOnlyList<StatedRuleCandidate>> ExtractAsync(string transcript, DateTimeOffset videoDateUtc, CancellationToken ct = default)
  Sequence:
    1. chunks = TranscriptChunker.Chunk(transcript)
    2. for each chunk: select = distiller.SelectStatedClaimsAsync(chunk); dis = distiller.DisambiguateStatedClaimsAsync(select.Claims); dec = distiller.DecomposeStatedClaimsAsync(dis.Claims, videoDateUtc)  -> collect dec.Rules
    3. reduced = distiller.ReduceStatedRulesAsync(allChunkRules, videoDateUtc)
    4. deduped = StatedRuleReducer.Reduce(reduced.Rules)
    5. grounded = ground card names: collect distinct non-null `CardReference` values across rules; call cardGrounder.TryGroundAsync per distinct CardReference (skip rules whose CardReference is null; skip the whole step when cardGrounder is null); on a resolved match rewrite that rule's `CardReference` to the canonical name and set CardGrounded=true; when unresolved set CardGrounded=false but KEEP the rule (D-07 — never drop). MUST NOT modify SourceClip (the audit field)
    6. DistillationValidation.ValidateStatedRules(grounded); return grounded
  Card-name detection is structural, not heuristic: a rule references a card iff its `CardReference` property is non-null (the Decompose stage, 96-03, populates it). Rules with a null CardReference are passed through untouched (CardGrounded stays null). Do NOT re-scan SourceClip/Condition for names.
