# Quick Task 260530-c72: cEDH meta-gap UI — remove Input Summary panel + mobile reference table

## Background

Two UI issues on `/cedh-meta-gap` Step 2:
1. The "Input Summary" `<pre>` panel echoes the filters + the full reference-deck
   list — redundant with the reference table directly below and with the saved
   `.zip` session artifact. User wants it gone on screen.
2. The "EDH Top 16 References" table (`conflicts-table[data-chatgpt-cedh-reference-table]`,
   9 columns) overflows on mobile: headers wrap char-by-char ("Sel ect", "Par tici
   pan ts", "De ckl ist"), dates stack. Needs a mobile-friendly layout.

## Constraints / scope fence

- `conflicts-table` is SHARED by DeckSync + CommanderCategories. The mobile rule
  MUST be scoped to `[data-chatgpt-cedh-reference-table]` so those tables are
  untouched.
- Layout CSS goes in `site-common.css` (per CLAUDE.md — NOT site.css / theme forks).
- Remove the on-screen panel ONLY. Leave `MetaGapViewModel.InputSummary`,
  `MetaGapService.BuildInputSummary`, and the packet/zip artifact build alone
  (still part of the saved session; `MetaGapServiceTests` covers it).
- LF line endings; touch only the lines that need touching; no reformatting.
