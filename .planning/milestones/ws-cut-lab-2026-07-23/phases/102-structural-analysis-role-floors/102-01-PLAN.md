<objective>
Build the floor domain layer for Cut Lab: the additive RoleFloors extension of the CutLabState
envelope, the serializer tamper-defense chain, the pure floor-evaluation contract Phase 103 must
call before proposing any cut (FLOOR-02), and the bracket/play-experience derived floor defaults
for all eight roles (FLOOR-01) including the one-word Core promotion of CalculateTargetRamp.

evaluation rule ships now as a unit-tested, pure API rather than view logic (RESEARCH Pitfall 7).

consume them.
Output: CutLabRoleFloor record + RoleFloors state member, CutLabFloorRules (ClampFloors +
Evaluate), CutLabFloorDefaults (defaults + merge + static table), public CalculateTargetRamp,
and three xUnit test files (new FloorRules/FloorDefaults, extended serializer tests).

- New xUnit files go FLAT in DeckFlow.Web.Tests/ (single namespace DeckFlow.Web.Tests, no subfolder).
