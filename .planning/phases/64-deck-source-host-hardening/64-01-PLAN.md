<objective>
Create the single source-of-truth host-trust helper `DeckSourceHost` in `DeckFlow.Core/Integration/`
and lock its accept/reject behavior with a pure unit-test matrix. This helper replaces the
substring `uri.Host.Contains("moxfield.com")` pattern that the four deck-source call sites use
today (adopted in plan 64-02). Landing the helper and its regression matrix first means the
SC3 guarantee — "tests fail if substring matching is reintroduced" — is enforceable before any
call site is touched.

Purpose: Close the host-spoof / look-alike-domain hole (SEC-01) with an exact-or-approved-subdomain
predicate, and make the regression guard (SEC-03) authoritative as a standalone artifact.
Output: `DeckSourceHost.cs` (new helper) + `DeckSourceHostTests.cs` (new pure predicate matrix).
</objective>
