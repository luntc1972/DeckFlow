## Trust Boundaries
`ArtifactPath` / `ChannelTitle` are operator/prod-sourced display strings parsed in-memory over
already-loaded rows. No SQL, no filesystem access, no path traversal (string split only).

## STRIDE Threat Register
- **Tampering (T-62-02):** a crafted ArtifactPath must not break parsing or escape the in-memory
  filter. Mitigation: pure string split with an "Unknown" fallback; never used as a path or SQL.
- **Integrity (T-62-03):** creator filter must compose with the Phase-61 visible projection so a
  filtered-out row can't be harvested. Mitigation: predicate folded into `GetVisibleChannelVideos()`,
  covered by a compose test.
