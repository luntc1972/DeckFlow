LOCKED DESIGN DECISIONS (from RESEARCH.md open questions — apply across the whole phase):
- D1/D3: Turn-1 availability averages across NON-COMMANDER castability rows; fall back to all rows only if there are zero non-commander rows.
- D2: cEDH renders the FULL card (the sim runs regardless of mode).
- D4: The ✓/⚠ threshold is a flat 80%, mode-independent, informational only — it NEVER affects the health verdict.
- D5 (denominator): "Untapped %" is computed over ALL colored sources via the existing `EffectiveSources` weighting (`ManaSource.EntersUntapped` is authoritative; rocks/dorks count as untapped-on-entry). This keeps the figure consistent with the sim.
- TAP-02 definition: "share of simulated games with ≥1 untapped mana source to spend on turn 1" — deck-level, NOT per-color.
