    LoopbackBindGuard.IsLoopbackBindUrl(url):
    - true for: "http://localhost:5271", "http://127.0.0.1:5271", "http://127.0.0.2", "https://[::1]:5271", "http://::1".
    - false for: "http://0.0.0.0:5271", "http://+:5271", "http://*:5271", "http://[::]:5271", "http://192.168.1.50:5271", "http://studio.example.com".
    LoopbackBindGuard.FindNonLoopbackBindings(urls): returns only the offending (non-loopback) URLs; empty list when all are loopback.
  </behavior>
  <action>
Create `DeckFlow.Studio/LoopbackBindGuard.cs` — an `internal static class LoopbackBindGuard` (file-scoped namespace `DeckFlow.Studio;`, full XML doc, per H2). Provide three members:

1. `IsLoopbackBindUrl(string url)` -> bool. Pure host classifier:
   - Trim; if null/whitespace treat as non-loopback (an empty bind spec is unsafe, fail closed).
   - Strip the scheme: take everything after "://" if present; otherwise use the whole string.
   - Take the authority: substring up to the first '/'.
   - If the authority starts with '[' (IPv6), the host is the text between '[' and ']'. Otherwise the host is the substring up to the first ':'.
   - Lowercase the host. Return false (non-loopback) for wildcard binds: empty, "+", "*", "0.0.0.0", "::", "[::]".
   - Return true for "localhost".
   - Else `IPAddress.TryParse(host, out var ip)` and return `IPAddress.IsLoopback(ip)` (covers 127.0.0.0/8 and ::1).
   - Else (a real DNS hostname) return false.

2. `FindNonLoopbackBindings(IEnumerable<string> urls)` -> `IReadOnlyList<string>`. Filter `urls` to those where `!IsLoopbackBindUrl(...)`; return as a list.

3. `GatherConfiguredBindUrls(IConfiguration configuration)` -> `IReadOnlyList<string>`. Glue that assembles the effective bind URLs in priority order: split `configuration["urls"]` on ';' (drop empties); collect every `Kestrel:Endpoints:{name}:Url` value under the `Kestrel:Endpoints` section; if the combined set is empty, fall back to the single default `http://localhost:5271`. Return distinct, trimmed entries.

Wire the guard into `DeckFlow.Studio/Program.cs` inside the existing `try` block, AFTER `builder.Configuration.AddUserSecrets<Program>().AddEnvironmentVariables()` and BEFORE `await app.RunAsync();` (place it right before `await app.RunAsync();`, using `builder.Configuration` which is still in scope — this fails fast before Kestrel ever binds). Logic: `var configuredUrls = LoopbackBindGuard.GatherConfiguredBindUrls(builder.Configuration);` then `var offending = LoopbackBindGuard.FindNonLoopbackBindings(configuredUrls);` if `offending.Count > 0`, `Log.Fatal(...)` a clear message naming the offending host(s) and explaining that Studio is an unauthenticated prod-publish tool that may only bind loopback (localhost / 127.0.0.1 / [::1]) and that the operator should fix `ASPNETCORE_URLS` / Kestrel config — then `throw new InvalidOperationException("DeckFlow Studio refuses to bind a non-loopback address ...");`. The existing outer `catch`/`finally` will log fatal and flush. Add a `// Why:` comment (reference H2) explaining the guard closes the only network-exposure hole.

Do NOT touch the auto-open-browser block (lines ~169-197): its `http://+`/`0.0.0.0`/`[::]` normalization is about display, not binding, and remains valid because the guard rejects those binds upstream. The default `http://localhost:5271` must continue to pass.

Add `using System.Net;` to LoopbackBindGuard.cs. Add the namespace `using` for the guard in Program.cs only if needed (same namespace `DeckFlow.Studio`, so no using required).

Create `DeckFlow.Studio.Tests/LoopbackBindGuardTests.cs` (xUnit, `public sealed class LoopbackBindGuardTests`, namespace `DeckFlow.Studio.Tests`, `using DeckFlow.Studio;`). Cover with `[Theory]/[InlineData]`:
   - Loopback-true cases listed in <behavior>.
   - Non-loopback-false cases listed in <behavior>.
   - One `[Fact]` for `FindNonLoopbackBindings` with a mixed list asserting it returns exactly the offending entries.
   - One `[Fact]` for `GatherConfiguredBindUrls` using an in-memory `ConfigurationBuilder().AddInMemoryCollection(...)` seeded with `Kestrel:Endpoints:Http:Url=http://localhost:5271` asserting the default localhost is gathered, and a second seeded with `urls=http://0.0.0.0:8080` asserting the wildcard is gathered (so the guard would reject it).
  </action>
