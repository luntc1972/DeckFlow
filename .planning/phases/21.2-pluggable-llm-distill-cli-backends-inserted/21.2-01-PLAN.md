<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| transcript text → CLI subprocess | Untrusted YouTube/podcast transcript content is fed to the LLM CLI via stdin |
| operator env (`DECKFLOW_LLM_CLI_COMMAND`) → process FileName/Arguments | Operator-controlled command string used to launch a child process |
| CLI stdout → JSON deserializer | Untrusted/unstructured model output parsed into typed payloads |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21.2-01 | Tampering | `ResolveCommand` / process Arguments | mitigate | Process args come ONLY from per-provider const defaults or the operator-set `DECKFLOW_LLM_CLI_COMMAND` — transcript content is NEVER concatenated into FileName/Arguments (it goes to stdin). `UseShellExecute=false` (no shell interpolation). Command source is the operator's own env, a trusted local boundary. |
| T-21.2-02 | Tampering | transcript → prompt injection into CLI | mitigate | A malicious transcript could attempt to alter the extraction. Output is constrained by shape-validation (required fields, ContentTagVocabulary allowlist applied downstream in Plan 02, summary ≤200 words). Transcripts are treated as untrusted; the parse pipeline rejects malformed/oversized output and retries, then marks the video failed (non-terminal). |
| T-21.2-03 | Denial of Service | hung/slow CLI subprocess | mitigate | `ExtractWithRetryAsync` threads the caller's `CancellationToken`; Plan 02 wires a 15-min-aligned timeout token (per RESEARCH discretion ~10 min/call). stdin closed + concurrent stdout/stderr reads prevent the pipe-buffer deadlock that would otherwise hang indefinitely. |
| T-21.2-04 | Information Disclosure | logging transcript/prompt text or secrets | mitigate | CliLlmDistillationService does NOT log prompt/transcript bodies; only structured failure messages with `Tail(stderr)` (bounded 800 chars). No API key is read or echoed (claude/codex use the operator's own OAuth session). |
| T-21.2-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed this phase (BCL only — `System.Diagnostics.Process`). RESEARCH Package Legitimacy Audit: satisfied by absence. No `[ASSUMED]/[SUS]/[SLOP]` packages → no install checkpoint required. |
</threat_model>
