    **SC #1 — Route templates, not literal paths:**
    Connect to production Postgres (Render dashboard -> Postgres "mtg-data" -> Connect via psql shell, or use saved connection string locally). Run:
    ```sql
    SELECT DISTINCT route_key FROM request_metrics ORDER BY route_key LIMIT 50;
    ```
    PASS condition: rows look like `DeckFlow.Web.Controllers.DeckController.Index (DeckFlow.Web)` or attribute-route templates like `Admin/Harvest`. NOT raw paths with card names, deck IDs, or query strings. Also: row count is well under ~100 (DeckFlow has <30 distinct routes).
    FAIL condition: thousands of distinct rows containing per-card or per-deck strings → cardinality blow-up; revisit middleware route_key extraction (Pitfall 7).

    **SC #2 — Static assets excluded:**
    ```sql
    SELECT COUNT(1) FROM request_metrics
     WHERE route_key LIKE '/css/%' OR route_key LIKE '/js/%' OR route_key LIKE '/lib/%' OR route_key LIKE '/extensions/%';
    ```
    PASS: returns `0`.
    FAIL: any positive count → static-asset filter (D-11) is broken; check middleware short-circuit ordering.

    **SC #3 — No PII columns (request_metrics has no IP at all; ip_hash only on side table):**
    ```sql
    \d request_metrics
    \d request_metric_ip_seen
    ```
    PASS conditions: `request_metrics` columns are exactly (`route_key`, `day_utc`, `status_class`, `hit_count`, `error_count`) — NO `ip_raw`, NO `ip_hash`, NO `ip` column. `request_metric_ip_seen` columns are exactly (`route_key`, `day_utc`, `ip_hash`) — `ip_hash` is the ONLY PII-adjacent column and it's hashed.
    Spot-check the hash format:
    ```sql
    SELECT ip_hash FROM request_metric_ip_seen LIMIT 1;
    ```
    PASS: returns a 64-character hex string (SHA-256 hex output).

    **SC #4 — Admin page renders correctly:**
    Visit https://www.deckflow.gg/Admin/Analytics in a private/incognito browser window with BasicAuth credentials (FEEDBACK_ADMIN_USER / FEEDBACK_ADMIN_PASSWORD from Render dashboard).

    - At least one route row is visible.
    - Each row shows: route name, hit count, unique-IP count, error-rate %, an inline SVG sparkline.
    - View source of the page: NO `<script src=` tag references chart.js, apexcharts, d3, highcharts, or any JS chart library. The sparkline is in `<svg><rect ...>` form rendered server-side.
    - The active range tab is visually highlighted.
