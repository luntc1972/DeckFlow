# 70-01 — MQ-01: Commander must not be drawn into the simulated library

**Finding:** Audit #3 (High, narrow). Verified in code.
**Risk:** Low. **Blast radius:** decks with a commander that is a mana source.

## Problem
`ManabaseAnalyzer.cs:55` sets `librarySize = TotalCards - CommanderCount`, but `BuildLibrary`
(`CastabilitySimulator.cs:230`) turns **every** `deck.Sources` entry into a drawable `LibraryCard`,
then pads/truncates to `librarySize`. Commander sources have no flag, so:
- a mana-dork commander (added by `AddPartialSources`) and
- the commander's `(granted)` any-color source (added by `AddGrantedSources`)

are drawn as if in the 99, and real cards get truncated to fit. Wrong cast% for commander-mana
decks (Selvala, Marwyn, Esika, Jodah).

## Side-effects
- **Files:** `ManabaseModels.cs` (ManaSource), `ManabaseClassifier.cs` (set flag),
  `CastabilitySimulator.cs` (filter in BuildLibrary).
- **Shared state:** none. **External:** none. **Contract:** `ManaSource` gains one optional field
  (default false) — additive, no serialization break.
- **Decision:** commander sources STAY in `EffectiveSources`/color counts (a commander mana source
  is reliably castable); only excluded from the drawable library.

## Steps
1. **`ManaSource`**: add `public bool IsCommander { get; init; }` (default false), xmldoc: "true for
   a source contributed by a command-zone card; such sources are not drawn into the simulated
   library but still count toward color supply."
2. **`ManabaseClassifier`**: set `IsCommander = card.IsCommander` everywhere a non-land source is
   built for a card — `AddPartialSources` (rock/dork), `AddGrantedSources` (the `(granted)` source),
   and `AddLandCopies`/`AddWeighted` paths if a commander can be a land (rare; set for completeness).
   Thread `card.IsCommander` into those helpers.
3. **`CastabilitySimulator.BuildLibrary`**: skip sources where `source.IsCommander` when emitting
   `LibraryCard`s (they are not in the 99). `librarySize` already excludes the commander count, so
   filler padding fills the freed slots correctly.
4. **Verify** `EffectiveSources` / `SourceBreakdown` still include commander sources (they read
   `deck.Sources` directly — unchanged). Confirm no double-subtraction of the slot.

## Tests (Core, xUnit — `ManabaseAnalyzerTests`)
- `Analyze_ManaCreatureCommander_NotDrawnIntoLibrary`: a Selvala-like commander (creature,
  `{T}: Add`); assert the commander does not appear as a library draw and cast% of a test spell is
  invariant whether an extra filler card is added or not (size-independence).
- `Analyze_GrantedCommanderSource_ExcludedFromLibrary_KeptInColorCount`: with a granter present,
  assert the commander `(granted)` source is in `ColorFindings` color supply but not duplicated as a
  drawable card.
- Regression: existing 129 manabase tests stay green.

## Done when
- Build clean; manabase suite green; the two new tests pass; cast% for a non-commander-mana deck is
  unchanged (no accidental shift). Codex review of the diff (per DeckFlow rule).
