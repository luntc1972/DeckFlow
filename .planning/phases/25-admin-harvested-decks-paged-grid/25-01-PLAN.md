## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | Tampering | `page` → OFFSET injection | mitigate | `@limit`/`@offset` bound via `RelationalDatabaseConnection.AddParameter` (parameterized); no string concat. Store clamps `page`/`pageSize` with `Math.Max(_, 1)` so OFFSET can never be negative. |
| T-25-02 | Denial of Service | huge `page` → enormous OFFSET scan | mitigate | LIMIT is a fixed server-side `pageSize` constant (set in 25-02 controller), never client-controlled. Upper-bound page clamp to total pages is enforced in 25-02. This plan caps OFFSET non-negative. |
| T-25-03 | Denial of Service | load all deck_queue rows into memory (512MB cap) | mitigate | Query is LIMIT/OFFSET only; repository returns at most pageSize rows. Test asserts page-1 of N returns exactly pageSize, not all rows. |
| T-25-04 | Information Disclosure | reltuples / pg_class read exposes stats | accept | pg_class.reltuples is non-sensitive planner metadata; admin-only surface; no PII. |
| T-25-SC | Tampering | npm/pip/cargo installs | accept | No package installs in this phase (research Package Legitimacy Audit: not applicable). No `[ASSUMED]`/`[SUS]` packages. |
</threat_model>
