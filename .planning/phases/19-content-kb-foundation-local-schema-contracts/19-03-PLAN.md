content_sources: id PK, source_slug TEXT NOT NULL, display_name TEXT NOT NULL,
  source_type TEXT NOT NULL CHECK(IN 'youtube_channel','podcast_rss'), source_url TEXT NOT NULL,

content_clips: id PK, video_id -> content_videos(id) ON DELETE CASCADE, timestamp_s INT NOT NULL, excerpt NOT NULL, sort_order INT NOT NULL DEFAULT 0
content_tags: id PK, video_id -> content_videos(id) ON DELETE CASCADE,

<type_mapping>
Postgres -> SQLite:
- BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY -> INTEGER PRIMARY KEY AUTOINCREMENT
- BIGINT (FK col) -> INTEGER
- TIMESTAMPTZ NOT NULL DEFAULT now() -> TEXT NOT NULL DEFAULT (datetime('now'))
- TIMESTAMPTZ NULL -> TEXT NULL
- BOOLEAN NOT NULL DEFAULT TRUE -> INTEGER NOT NULL DEFAULT 1
- REFERENCES parent(id) ON DELETE CASCADE -> identical syntax (fires only with PRAGMA foreign_keys=ON)
- CHECK (x IN (...)) -> identical
</type_mapping>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-19-07 | Tampering (SQL injection) | All parameterized queries in both stores | mitigate | Every value bound via `RelationalDatabaseConnection.AddParameter`; zero string-concatenated SQL — mirrors existing stores |
| T-19-08 | Tampering / Integrity | Orphan child rows if CASCADE no-ops on SQLite | mitigate | Stores open via Plan 02 `OpenConnectionAsync` (FK pragma ON); D-04 CASCADE proof [Fact] fails loudly if the pragma regresses |
