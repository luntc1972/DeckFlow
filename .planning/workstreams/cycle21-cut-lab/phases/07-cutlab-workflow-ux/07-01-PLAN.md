<task type="auto">
  <name>Task 1: Write the gate assertions</name>

  Create `DeckFlow.Web/e2e/cut-lab-workflow-ux.spec.ts`. Import the pool with the
  same 17-row fixture `cut-lab-smoke.spec.ts` uses so heights stay comparable to
  the recorded baseline.

  **G-1 Five-slot contract.** Phase 7's canonical wizard contract is five slots in
  document order: Process (`cut-lab-step-panel-1`, index 1), Decide
  (`cut-lab-step-panel-2`, index 2), **Plan** (`cut-lab-step-panel-3`, index 3,
  reserved as an empty element), Goals
  (`cut-lab-step-panel-4`, index 4), and Export (`cut-lab-step-panel-5`, index 5).
  Phase 8's plan panel is the sole consumer of `cut-lab-step-panel-3`; it fills
  that numeric slot without restructuring the wizard. Query `[role="tabpanel"]` and assert the `id` sequence in
  DOM order is exactly `["cut-lab-step-panel-1", "cut-lab-step-panel-2",
  "cut-lab-step-panel-3", "cut-lab-step-panel-4", "cut-lab-step-panel-5"]`. Use document order
  (`querySelectorAll` returns it), not `offsetTop` — offsets are style-dependent.

  **G-2 Tab activation.** For each enabled step: scroll to 0, snapshot
  `aria-selected` across all tabs and `display` across all panels, then
  `btn.dispatchEvent(new MouseEvent('click', { bubbles: true, cancelable: true }))`,
  then re-snapshot. Assert `aria-selected` moved to the clicked tab AND exactly
  exactly one panel is not `display: none`, and only its tab has `.is-active`.

  Do NOT use `page.click()` here. Playwright scrolls the target into view before
  clicking, which changes `window.scrollY` even when the handler is a no-op —
  that artifact is what made the first manual probe read as a partial pass.

  **G-3 Page bulk.** Assert `document.documentElement.scrollHeight` is under
  3,000px at 1440×900 and under 4,000px at 390×844, on the Decide step, with the
  17-row fixture. Thresholds are headroom-generous against the selected Option 3
  target (~1,107px desktop) so ordinary copy edits do not trip the gate; today's
  10,453 / 15,896 fail them by a wide margin.

  **G-4 Intake collapsed.** After a successful import assert the intake form is
  not rendered expanded — the deck textarea (`#cut-lab-deck-text`) is either
  absent or inside a closed disclosure, and a summary element carrying the
  commander name is visible within the first viewport height.

  Each assertion gets its own `test(...)` so a failure names the property.
</task>
