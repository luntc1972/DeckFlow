# Plan 108-02 — JSON Mutation Endpoint Patch Responses

<objective>
Wire Cut Lab JSON mutation endpoints to return the shared server-authored patch after decisions, quantity adjustments, and what-if commits.
</objective>

<threat_model>
T-108-03: Response-shape changes could accidentally drop same-origin, feature-flag, request-size, or invalid-state protections. Mitigation: keep existing endpoint attributes and validation branches; only change success payload shaping after mutation rules pass.

T-108-04: What-if commit could produce a patch for a half-applied swap. Mitigation: preserve the existing restore-then-accept atomicity check and return `BadRequest` before patch building when the replacement cut is refused.
</threat_model>

<must_haves>
- `POST /api/cut-lab/decide` returns a patch for the post-decision state.
- `POST /api/cut-lab/adjust` returns a patch for the post-adjustment state.
- `POST /api/cut-lab/whatif/commit` returns a patch for the committed swap state.
- `POST /api/cut-lab/whatif` preview stays non-mutating and does not need a full patch in Phase 108.
- Existing `FeatureFlagGate("tool.cut-lab.enabled")`, `RequestSizeLimit`, and same-origin checks remain intact.
</must_haves>
