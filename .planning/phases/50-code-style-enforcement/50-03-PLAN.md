Add the FMT-02 carve-out guard test: an xUnit test that formats four code fixtures with the reconciled `.editorconfig`, using the SAME `dotnet format` mode the Plan 02 gate uses, and asserts each is byte-identical afterward. CRITICAL: it must exercise the SAME mode the gate enforces (FULL `dotnet format` by default per 50-02) — a whitespace-only guard would under-protect init/switch if a gate-enforceable style/severity key is later adopted.
