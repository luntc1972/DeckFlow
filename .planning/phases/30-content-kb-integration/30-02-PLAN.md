| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-04 | Elevation of Privilege | Artifact path read via ContentSiteIndexRow.ArtifactPath | mitigate | All reads go through ContentKbArtifactPathResolver.ResolveArtifactFullPath (Path.GetFullPath + Combine anchored to ContentBase) — never raw concatenation |

| T-30-06 | Tampering | Deserialization of user-uploaded zip 32-expert-context.json | mitigate | ContentKbExcerpt is a closed DTO of primitive types deserialized with System.Text.Json (no polymorphism, no type names in payload); allowlist throws on unexpected entries |
| T-30-07 | Denial of Service | Oversized/maliciously long clip text inflating prompt/zip | mitigate | 150-word cap + sentence-boundary truncation per clip (D-04); K=5 hard cap on clip count |
