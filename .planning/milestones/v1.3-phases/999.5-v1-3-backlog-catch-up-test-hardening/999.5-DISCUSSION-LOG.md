## FeedbackStore lock-race fix shape

| Option | Description | Selected |
|--------|-------------|----------|
| ClearAllPools before Delete | `SqliteConnection.ClearAllPools(); GC.Collect(); GC.WaitForPendingFinalizers();` then `File.Delete`. Root cause = Microsoft.Data.Sqlite pool retention. Canonical .NET pattern. | ✓ |
| Polly retry on Delete | Wrap `File.Delete` in Polly retry (3 attempts, 100ms backoff). Masks the root cause. | |
| Skip Delete — leak %TEMP% | Remove `File.Delete` from Dispose. OS cleans %TEMP% eventually. | |
| [Collection] serialize tests | Add `[Collection("FeedbackStoreSerial")]` to disable parallel execution. Slower; doesn't help cross-class. | |

**User's choice:** ClearAllPools before Delete (recommended option).
**Notes:** Captured as D-01 + D-02 + D-03 in CONTEXT.md. D-03 extends the same pattern to any sibling test class with a `File.Delete(_dbPath)` shape — sweep before commit.
