# Phase 07.1 Plan 01: Categories Feature Flag Kill-Switch Summary

**Default-on `feature.categories.enabled` flag seeded on both Postgres and SQLite, gating four surfaces on a single key: GET + POST `/suggest-categories` (via `[FeatureFlagGate]` attribute), the AI Category Suggestions nav entry in `_DeckToolTabs.cshtml`, and the AI Category Suggestions hub-card on `Home.cshtml`. Operator toggles OFF in `/Admin/Flags` → all three user-facing surfaces (nav, landing CTA, route 503) flip together within ~30s without app restart. Category Reference stays visible — only the broken AI suggestions flow is hidden. Build clean across all three tasks.**
