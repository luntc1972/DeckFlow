**Tab activation pattern** (lines 498–524):
```typescript
const activateStepTab = (button: HTMLButtonElement, focusPanel = false): void => {
  const step = button.getAttribute('data-cut-lab-step');
  if (!step) {
    return;
  }

  const panels = Array.from(document.querySelectorAll<HTMLElement>('[role="tabpanel"]'));
  const targetPanel = panels.find(panel => panel.id === `cut-lab-step-panel-${step}`);
  if (!targetPanel) {
    return;
  }

  if (readCollapsedSectionIds() === null) {
    applyDefaultSectionCollapseState(step);  // FIX: avoid collapse side effect on init
  }

  panels.forEach(panel => {
    panel.toggleAttribute('hidden', panel !== targetPanel);
  });
  getStepTabs().forEach(tab => {
    const isActive = tab === button;
    tab.setAttribute('aria-selected', isActive ? 'true' : 'false');
    tab.setAttribute('tabindex', isActive ? '0' : '-1');
    tab.classList.toggle('is-active', isActive);
  });

  if (focusPanel) {
    focusJumpTarget(targetPanel);
    scrollJumpTargetIntoView(targetPanel);
  }
};
```

## Shared Patterns

### R2-1 Fix: Keyboard Navigation Focus vs. Selection

**Source:** `cut-lab.ts:551–572` + `cut-lab-step-tabs.test.ts:70`

**Core principle:** Focus (what receives keyboard input) and selection (which tab is "current") are separate concerns in a roving tablist.

```typescript
// WRONG: filter on !tab.disabled (also skips planning from focus ring)
const enabledTabs = getStepTabs().filter(tab => !tab.disabled);

// RIGHT: filter on aria-disabled only for selection; keep all tabs in focus ring
const focusableTabs = getStepTabs().filter(tab => true);  // all tabs can be focused
const selectableTabs = getStepTabs().filter(tab => tab.getAttribute('aria-disabled') !== 'true');  // only non-disabled can become selected
```

**Apply to:** ArrowLeft, ArrowRight, Home, End key handlers.

### F-5 Fix: Panel Hiding on Init Without Collapse Side Effect

**Source:** `cut-lab.ts:506–508` (the trap) + `cut-lab.ts:526–541` (init handler)

**Trap:** Calling `activateStepTab` on init to hide panels runs the collapse default, moving which sections are open on arrival.

```typescript
// WRONG: routes init hiding through activateStepTab, runs collapse logic
if (readCollapsedSectionIds() === null) {
  applyDefaultSectionCollapseState(step);  // runs on every page load
}

// RIGHT: hide panels without the collapse side effect
const hideNonSelectedPanels = (): void => {
  const panels = Array.from(document.querySelectorAll<HTMLElement>('[role="tabpanel"]'));
  const selectedStep = document.querySelector<HTMLButtonElement>('[role="tab"][aria-selected="true"]')
    ?.getAttribute('data-cut-lab-step');
  
  panels.forEach(panel => {
    const panelStep = panel.id.match(/\d+$/)?.[0];
    panel.toggleAttribute('hidden', panelStep !== selectedStep);
  });
};

// Call on init, before collapse default
hideNonSelectedPanels();

// Then run collapse default only if no stored state
if (readCollapsedSectionIds() === null) {
  applyDefaultSectionCollapseState(step);
}
```

**Test:** Assert first-load collapsed-section state is unchanged after init hiding.
