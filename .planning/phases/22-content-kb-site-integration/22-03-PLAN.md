<locked_decisions>
## D-22A — artifact_path canonical convention (LOCKED, inherited from Plan 01/02)
`artifact_path` = `content-kb/{source-slug}/{id}.md` — the `content-kb/` prefix is PART of the stored/seeded value. The controller resolves `resolved = Path.Combine(contentBase, artifact_path)` where `contentBase` CONTAINS `content-kb/` — NOT the `content-kb/` dir itself. Combining a `content-kb/`-prefixed path against a `content-kb/` base would yield `/app/content-kb/content-kb/...` — DO NOT do that (review HIGH-3).

## D-22B — content base resolver (LOCKED, ordered candidates; resolves review HIGH-6)
No single hardcoded base works (Docker ContentRootPath=/app; local dev ContentRootPath=DeckFlow.Web project dir). `ContentKbArtifactPathResolver` resolves `contentBase` as the FIRST existing candidate, in order:
  1. config override `ContentKb:ContentBase` if set and non-empty,
  2. `Path.Combine(env.ContentRootPath, "content-kb")`'s PARENT — i.e. `env.ContentRootPath` (Docker route, D-22B: COPY puts files at /app/content-kb, base = /app),
  3. `Path.GetFullPath(Path.Combine(env.ContentRootPath, ".."))` (local dev: DeckFlow.Web/.. = repo root, which contains content-kb/),
  4. `Directory.GetCurrentDirectory()` fallback.
A candidate "exists" when `Directory.Exists(Path.Combine(candidate, "content-kb"))`. Log the chosen base + whether content-kb/ exists under it at startup (one info line) so Pitfall 4 is diagnosable in deploy logs. The resolver is the single source of truth for BOTH the seed-file path (`{base}/content-kb/seed/index-seed.json`) and artifact reads (`Path.Combine(base, row.ArtifactPath)`).

## D-22C — detail route keyed by row id (LOCKED; resolves MED route-safety)
The detail route is `/content-kb/{id:long}` using the surrogate `content_site_index.id` (always a safe integer) — NOT `{sourceSlug}--{naturalKey}`. RSS podcast GUIDs can contain `/ ? # --` and are unsafe in a path segment; the slug--key scheme is dropped. The controller resolves the row via `store.GetByIdAsync(id)` (added in Plan 01). Browse-page links emit `/content-kb/{row.Id}`.
</locked_decisions>
