<objective>
Deliver the what-if swap backend (GOAL-03): a non-destructive preview endpoint and a single atomic commit endpoint, plus the "whatif-swap" round key. The preview computes before/after deltas by calling the reused `BuildSnapshot` twice and diffing with `CutLabMetricDelta.Between` — never touching server state. Commit composes the two existing decision primitives (`Restore(B)` then `Accept(A)`) in one request. Both honor the user's goal turns and the same-origin/size/flag guards the decide endpoint already uses. UI is 104-05.

Purpose: The swap must be computable and committable safely on the server before any picker or Keep/Discard button exists.
Output: `CutLabWhatifApiRequest`/`Response`, `PostWhatifAsync`, `PostWhatifCommitAsync`, and the registered round key.
</objective>
