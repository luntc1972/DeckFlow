<objective>
Build the Core capabilities the Publish page (Plan 04) needs:

1. **`IGitRepository` git shell-out service** (`DeckFlow.Core/Integration/`) — wraps `git` via
   `Process.Start` (mirroring `FfmpegAudioChunker`), exposing: current branch, repo root, a textual
   diff of given paths, HEAD's committed seed contents, and a **pathspec-scoped** stage+commit that
   commits ONLY the listed paths and refuses to sweep in unrelated pre-staged changes. It **never
   pushes** (D-01) and **never `git add -A`** (scoped paths only — Claude's-discretion dirty-tree
   handling).
2. **`ExportIndexToFileAsync` on the orchestrator** — relocates the CLI's LF seed-serialize+write
   into Core (Studio cannot reference CLI), writing the approved-only seed with explicit LF (D-13)
   so a Windows-run Studio never emits CRLF (SC5). The JSON byte-shape is golden-test-pinned — change
   LF + file-write location only, never the shape.
3. **`CopyApprovedArtifactsToRepoAsync` on the orchestrator** — materializes the approved markdown
   artifacts from the Studio data root into the repo working tree so the publish commit ships real
   files (D-03/PUB-03). Studio writes artifacts under `ArtifactRoot = {studioData}/content-kb`, but
   the publish commit stages `repoRoot/content-kb/{slug}/{id}.md` — those files do NOT exist in the
   repo tree until copied. This method takes the data root (= parent of `ArtifactRoot`), the repo
   root, and the approved rows, COPIES each artifact source→dest with containment guards on BOTH
   ends, errors (never silently skips) on a missing source, creates destination dirs, and returns the
   copied repo-relative paths for staging. This **resolves the CONTEXT "Claude's Discretion:
   repo-root / git working-dir resolution + dirty-tree handling" item** — the publish flow copies
   data-dir artifacts into the git-resolved repo root, then scope-commits only those paths.

Purpose: Studio is decoupled from `DeckFlow.CLI`; today the serialize+write lives in
`ContentKbCommandRunners`. This plan moves the byte-shape-stable write into Core, adds the artifact
materialization copy (so the committed seed never references files absent from the repo), and adds the
git service so Plan 04 is pure UI wiring.

Output: `IGitRepository` + `GitRepository`, two orchestrator methods (seed file-write + artifact copy),
and tests pinning LF + byte-shape + the copy/containment behavior.
</objective>
