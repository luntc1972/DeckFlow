<objective>
Ship the Studio I/O orchestrator that composes the reconcile dry-run: read prod ONCE via the extended
`ProdContentReader`, enumerate the git `content-kb/**/*.md` tree (the genuinely-new file->row capability,
Pitfall 6), read `index-seed.json` via `SeedIndexFileReader.Read` (availability-aware), feed all inputs
to the pure `ContentKbReconcileClassifier`, persist scope-tagged results to the local store, and write
the D-06 human-readable report. Mirrors `GitBodyCoverageAudit`'s shape and reuses every existing I/O seam.

Purpose: Turn the pure classifier into a runnable dry-run that reads all three inputs safely and
records results - the always-available (flag-independent) detection surface. The orchestrator reads the
seed with the availability-aware `Read` and returns a `ReconcileDryRunResult` carrying `SeedAvailable`
straight from `SeedIndexFileReader.Read` (NOT inferred from the discrepancy list), so the downstream
Apply (91-08) can independently refuse on an unavailable seed and the operator sees a "seed unavailable
- seed-drift/removal skipped" notice instead of phantom drift (Codex BLOCK).
Output: `IContentKbReconcileOrchestrator` + `ContentKbReconcileOrchestrator` + `ReconcileDryRunResult`
+ report writer + registration.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| prod DB -> orchestrator (read) | Single read-only SELECT via ProdContentReader; no DDL, no write |
| git filesystem -> orchestrator | Enumerated/opened .md files; path traversal risk if paths trusted blindly |
| seed file -> orchestrator | Read via SeedIndexFileReader.Read; availability flows to ReconcileDryRunResult, never collapsed to empty |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-91-14 | Tampering / Elevation of Privilege | Path traversal via a crafted ArtifactPath (row->file) or enumerated file (file->row) | mitigate | ArtifactPathSafety.TryBuildContainedPath / IsSafeArtifactPath on BOTH directions before any File access (V5) |
| T-91-15 | Denial of Service | Unbounded/per-row prod queries on dry-run | mitigate | Read prod ONCE per run (spy test asserts single read), mirroring GitBodyCoverageAudit |
| T-91-16 | Information Disclosure | Prod conn-string leaking via orchestrator logs | mitigate | Preserve ProdContentReader catch discipline; no new logging path surfaces the conn string |
| T-91-26 | Tampering | An unavailable seed silently producing an empty seed-drift section read as "no drift", or a collapsed empty set feeding Apply | mitigate | Orchestrator reads via SeedIndexFileReader.Read, passes the availability-aware SeedIndexReadResult to the classifier, returns SeedAvailable in ReconcileDryRunResult, and renders a "seed unavailable - skipped" notice; downstream Apply independently refuses on SeedAvailable==false |
