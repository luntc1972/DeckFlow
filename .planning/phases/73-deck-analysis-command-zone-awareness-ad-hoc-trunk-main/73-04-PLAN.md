<objective>
Surface the companion designator in the deck-analysis UI so the awareness feature works for Archidekt
and pasted-text decks (which never emit `DetectedCompanionName` — research §RQ3/§Pitfall 5), at parity
with the manabase companion input. The field is gated on `analysis.command-zone-awareness`; when the
flag is OFF the page is unchanged.

Scope note (recorded decision): the designator is a MANUAL input — its primary value is decks where
auto-detection cannot fire (Archidekt, pasted text, Moxfield-Spellbook fallback). Auto-detect pre-fill
into the visible input is NOT required here because the detected companion is only known after the
Step-2 build, and Moxfield-direct decks already get the companion via auto-detect in the service
(Plans 02/03). The typed value round-trips via the form-bound `Request.CompanionName` (added in Plan 01)
and the service already prefers the designator over the detected value (`ResolveCompanionName`, Plan 02).

Purpose: complete companion coverage across all deck sources + document the feature.
Output: flag-gated Step-1 companion input, controller flag plumbing, README + Help, Playwright smoke,
and an operator cross-theme/mobile visual sign-off.
</objective>
