## Spacing Scale

Project uses `rem` with `html { font-size: 15px }`. All values below map to multiples of 4px.

| Label | rem | px equiv | Usage in this phase |
|-------|-----|----------|---------------------|
| xs | 0.25rem | ~4px | Icon gaps, inline element separation |
| sm | 0.5rem | ~8px | Tight internal padding, filter gaps |
| md | 1rem | ~15px | Default card padding, grid gap |
| lg | 1.5rem | ~23px | Hero band padding-block, panel padding |
| xl | 2rem | ~30px | Page-level top margin (admin-feedback, feedback-page) |
| 2xl | 3rem | ~45px | Page bottom padding |

## Color

**Source**: Phase 01 tokens propagated to all 22 guild themes. Do NOT add new `:root` tokens — reuse all.

| Role | Token | Hex (classic Jeskai default) | Usage in this phase |
|------|-------|------------------------------|---------------------|
| Dominant (60%) | `--bg` | #eceef3 | Page background — unchanged |
| Secondary (30%) | `--panel` | #fafafa | Card backgrounds, hero band bg, feedback panel bg, admin detail bg |
| Accent (10%) | `--cta-border` / `--accent` | resolves to `--accent` (#2b6cb0) | Hub hero border, `.hub-card--primary` border, `.feedback-submit` bg |
| Destructive | `--danger` | #c53030 | Delete button in admin action forms; `.feedback-error` text |

**Accent reserved for** (exhaustive list — accent must not appear on any other element):
1. `.hub-hero` — left or top border accent stripe (`border-left: 4px solid var(--cta-border)`)
2. `.hub-card--primary` — accent border on all four sides (`border-color: var(--cta-border)`)
3. `.feedback-submit` — button background uses `--accent-strong`; matches existing pattern
4. `.run-button` / `.copy-button` — already established, unchanged
5. `.feedback-submit:disabled` — desaturated via `opacity: 0.55; filter: saturate(0.35)` (matches existing `.run-button:disabled` pattern in site-common.css)
6. Spinner ring top-color — `--accent` (see busy state below)

**60/30/10 split note**: The home hub hero band uses `--panel` (secondary surface) as its background. It is NOT a full-bleed accent background — that would break the 60/30/10 balance and fail on dark guild themes. Accent appears only as the border/stripe signal.

### 6. Feedback Busy State — Button Spinner (UX-02)

**CSS** (in site-common.css):

```
/* Feedback submit: busy state ring spinner */
.feedback-submit--busy
  Opacity: 0.75
  Cursor: not-allowed
  Position: relative
  Padding-left: 2.25rem    ← make room for spinner

.feedback-submit--busy::before
  Content: ""
  Position: absolute
  Left: 0.65rem
  Top: 50%
  Transform: translateY(-50%)
  Width: 0.9rem
  Height: 0.9rem
  Border: 2px solid rgba(255, 255, 255, 0.35)
  Border-top-color: var(--on-accent)
  Border-radius: 999px
  Animation: busy-spin 0.75s linear infinite
  /* busy-spin @keyframes already defined in site.css — reuse */
```

**No new `@keyframes` declaration needed.** `busy-spin` is already defined in site.css (lines 1107–1115). The `::before` pseudo-element approach requires no DOM mutation for the spinner itself.

**TypeScript** (extend site.ts — add `attachFeedbackBusyState()` function):

Pattern mirrors `attachArchidektCacheJobUi()` — attach on DOMContentLoaded and on readyState !== 'loading'.

Contract for the TS function:
```
attachFeedbackBusyState():
  - Selector: form.feedback-form (scopes to feedback page only — will be a no-op on all other pages)
  - On 'submit' event:
      1. Find button.feedback-submit within the form
      2. Set button.disabled = true
      3. Add class 'feedback-submit--busy' to button
      4. Swap button.textContent to "Sending…"  (D-09)
      5. Do NOT intercept the POST — let the form submit normally (D-08)
  - Graceful fallback: if JS disabled, form POSTs normally; user sees no spinner (D-10)
  - Double-submit: button.disabled prevents re-click (D-11)
```

**No server-side changes required for busy state.**

### Feedback submit button

| State | Visual |
|-------|--------|
| Default | `background: var(--accent-strong)`, `color: var(--on-accent)` (existing `.feedback-submit`) |
| Hover | `filter: brightness(1.1)` (existing) |
