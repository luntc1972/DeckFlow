<objective>
Build the creator-scoped deck cache that lets a re-run against the same creator avoid re-hitting Archidekt (CS-04b / D-02). It mirrors `ArchidektDeckCacheSession`'s SHAPE (content-hash-based freshness) but writes to its OWN `creator_deck_cache` table — it must NEVER touch `card_category_observations` / `sources` / `deck_queue`, because those back the D-07 global lift baseline and writing the creator's own decks there would self-pollute their own denominator (Pitfall 3). To satisfy D-02's intent ("re-running does NOT re-hit Archidekt"), the cache also persists each deck's full entry list (`entries_json`) so a warm-cache run can rebuild the `CreatorDeckSample` set purely from the cache with ZERO importer/HTTP calls (HIGH-2).

Purpose: CS-04b caching without corpus self-pollution, and without re-fetching on a warm cache.
Output: One new dialect-guarded creator-scoped cache store persisting serialized entries, round-trip + freshness tested.
</objective>
