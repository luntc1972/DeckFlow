<objective>
Build the one genuinely new piece of logic this phase needs: a **pure, fully unit-testable composer** that turns a final 100-card `DeckEntry` list + the captured original list into the four copy blobs (Moxfield full, Archidekt full, Moxfield patch, Archidekt patch) plus a validation summary. It composes existing, test-proven Core engines — `FullImportExporter`, `DiffEngine`, `DeltaExporter` — and reuses the color-identity subset check. No new export/diff math. Living in `DeckFlow.Core` keeps it HTTP-free and covered by `DeckFlow.Core.Tests` (surface-testable-coverage rule).

Purpose: Concentrate all export decisions (dialect formatting, board normalization for the full list, CUT/ADD grouping incl. quantity decreases, count/color/banlist validation, hard-block-on-count-only) behind one deterministic, unit-tested boundary so the Web wiring (105-04) stays thin.
Output: `CutLabExportComposer` + `CutLabExportResult` + `CommanderIdentityCheck`, plus Core tests including Cut-Lab-shaped Archidekt export, board-normalized full list, and cut-only + quantity-decrease diff cases.
</objective>
