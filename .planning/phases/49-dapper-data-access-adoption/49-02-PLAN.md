  - Parse: DateTimeOffset dto => dto; DateTime dt => new DateTimeOffset(SpecifyKind(dt,Utc));
    string => DateTimeOffset.Parse(text, Invariant, RoundtripKind | AssumeUniversal|AdjustToUniversal);
    else => Convert / fallback.
  - SetValue: SqliteParameter => value.UtcDateTime.ToString("O", InvariantCulture);
    else => value.UtcDateTime (PG TIMESTAMPTZ native).
  - Register it inside EnsureRegistered() with the other handlers.
