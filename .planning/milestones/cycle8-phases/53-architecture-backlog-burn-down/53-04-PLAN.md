Purpose: `IRelationalDialect` is a shared Core storage abstraction; feedback SQL is a Web feature concern that has no business in Core. Removing it tightens the layer boundary with zero behavior change.
Output: A trimmed Core dialect interface + impls, a new Web `FeedbackDialect`, and a `FeedbackStore` that consumes it.

Behavior-preservation proof: the three SQL fragments are moved verbatim (same TEXT/TIMESTAMPTZ column types, same ORDER BY clauses, same RETURNING-id insert); the existing `FeedbackStore` tests + solution build confirm feedback persistence and querying are unchanged on both providers.
</objective>
