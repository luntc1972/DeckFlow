<objective>
Build the Web-side I/O orchestrator that turns a loaded submitted deck into the statistics the pure rubric scorer (Plan 99-01) diffs against — plus the `CardGroundingDeckContext` the artifact assembler (Plan 99-03) needs — from a single Scryfall resolution pass.

Purpose: CS-27 requires the submitted deck's stats be computed the SAME way the creator's fused targets were, or the diff is meaningless (Pitfall 1 in numeric form). This plan reuses those exact paths for the submitted deck. It also emits the deck-context inputs the Phase 98 guard/whitelist need (Phase 99 is `CreatorWhitelistPoolBuilder`'s first real caller).
Output: `ISubmittedDeckStatsBuilder` + `SubmittedDeckStatsBuilder` + a `SubmittedDeckAnalysis` result record, with a test-seam constructor.
</objective>

| T-99-02-SC | Tampering | package installs | accept | No new packages introduced; no supply-chain surface. |
