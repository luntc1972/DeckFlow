## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-95-06-01 | Denial of Service (malformed/oversized payload) | Archidekt JSON responses / >105-card decks | mitigate | `MaxResponseBytes` cap checked BEFORE `JsonDocument.Parse`; `catch (JsonException)` fails the crawl step gracefully (no unhandled throw); drop `Size > 105` before fetch; each deck fetch flows through Polly (retry/timeout) not raw HTTP (MED-1) |
| T-95-06-02 | Tampering/Elevation (SSRF) | manual profile-URL fallback | mitigate | `ArchidektOwnerUrl.TryGetUsername` accepts only `uri.Host == archidekt.com` OR `*.archidekt.com` (case-insensitive host match, NOT substring), requires HTTPS, and rejects lookalike/userinfo/link-local/private-IP targets before the URL is used to build a request; tested with link-local, lookalike, userinfo, and non-HTTPS targets (MED-2) |
| T-95-06-03 | Denial of Service (unbounded pagination) | `next`-followed deck-list loop | mitigate | Hard MaxPages/MaxDecks ceiling; never trust `next` unconditionally (mirror ArchidektRecentDecksImporter's `count` cap) |
| T-95-06-04 | Denial of Service (third-party ToS / hammering) | crawl rate | mitigate | Reuse named Polly pipeline + content-hash read-through cache with entries_json warm-cache reuse so re-runs do not re-hit Archidekt (CS-04b) |

| T-95-06-06 | Injection | username in outbound query | mitigate | RestSharp `AddQueryParameter` URL-encodes; no string interpolation into the URL (V5) |
| T-95-06-SC | Tampering | package installs | mitigate | No new NuGet packages this plan (RestSharp/Polly/System.Text.Json already present) |
