### `DeckFlow.Web/Services/ArchidektCacheJobService.cs` — −12/+2 lines (net −10)

Rewired `GetJob(Guid jobId)` at lines 207-222: replaced the 16-line implementation (which had the "We don't have a GetByIdAsync" T-07-10 comment block + `GetActiveAsync` call + id-filter + branch) with a 5-line delegation to `_runStore.GetByIdAsync`:

```csharp
/// <inheritdoc />
public ArchidektCacheJobStatus? GetJob(Guid jobId)
{
    var row = _runStore.GetByIdAsync(jobId, CancellationToken.None).GetAwaiter().GetResult();
    return row is null ? null : MapToStatus(row);
}
```

The obsolete forward-reference comment ("Plan 04 will add one") is now resolved by THIS plan and was deleted. `/// <inheritdoc />` preserved. Sync wrapper pattern (`.GetAwaiter().GetResult()`) preserved — admin/API surface, sub-1RPS, no thread-pool starvation risk (T-07-10 rationale carries forward).
