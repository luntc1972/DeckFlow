<objective>
Build the SYNC-11 heart as a pure, I/O-free Core classifier: given already-loaded in-memory inputs
(extended prod rows, the set of existing git-tree body paths, and the availability-aware
`SeedIndexReadResult`), emit the four discrepancy classes - published-orphan, file-orphan, seed-drift,
body-hash-mismatch - each with a deterministic ID. Mirrors `ContentSyncDiffClassifier`'s shape exactly;
no DB, no git process, unit-testable with zero mocks.

Purpose: Keep the highest-risk reconcile logic in pure Core where it is exhaustively testable
(VALIDATION rows 91-XX-05..09). The Studio orchestrator (91-06) does the I/O and passes collections in.
Because an unavailable seed cannot be distinguished from a seed that legitimately removed every key,
seed-drift is GATED on `SeedIndexReadResult.SeedAvailable` - the classifier never emits seed-drift for
an unavailable seed, so an unreadable seed can never mass-flag every seed-owned row (Codex BLOCK).
Output: `ContentKbReconcileClassifier` + `ContentKbReconcileDiscrepancy` records + deterministic IDs.
</objective>
