<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uploaded zip -> LoadPrimerFromZip | Untrusted re-uploaded archive (path traversal, zip bomb, unlisted entries); enforced by ReadEntries |
| restored request state -> downstream | Bracket/platform/sections restored from the zip are re-normalized by the service's NormalizeSelections before use |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-14 | Tampering | Zip path traversal on a re-uploaded primer archive | mitigate | LoadPrimerFromZip delegates to ReadEntries, which rejects entry.FullName containing '/' and enforces PrimerAllowedNames; no custom archive parsing |
| T-31-15 | Denial of Service | Zip bomb / oversized primer upload | mitigate | ReadEntries enforces MaxEntryUncompressedBytes (2MB) + MaxTotalUncompressedBytes (10MB); reused unchanged |
| T-31-16 | Tampering | Spoofed cross-workflow zip (analysis/comparison entries) loaded as a primer | mitigate | PrimerAllowedNames is the only allowlist passed to ReadEntries for the primer load path; non-primer entry names throw; unit-tested |
| T-31-17 | Tampering | Restored SelectedSectionIds containing crafted/cross-bracket IDs | mitigate | Restored IDs are re-run through PrimerSectionCatalog.NormalizeSelections (in the service, 31-03) before use; the zip is not a trust bypass |
| T-31-SC | Tampering | npm/pip/cargo installs | accept | Zero package installs (RESEARCH §Package Legitimacy Audit: not applicable) |
</threat_model>
