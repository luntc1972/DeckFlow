<objective>
Land Sweep 3 of the WDG audit: apply the v1.2 commit `32bf620` Razor `selected=` pattern across DeckSync, DeckConvert, SuggestCategories, and AdminHarvest/Index views.

Purpose: Razor's default boolean rendering emits `selected="True"` when the expression is a boolean — invalid HTML. The fix (per D-09) is the ternary `selected="@(condition ? "selected" : null)"` which Razor renders as `selected="selected"` when true and omits the attribute entirely when false. Pattern was established by v1.2 commit 32bf620 on the ChatGPT views; this sweep propagates it to the remaining four views.

Output: Four updated Razor views with the fix applied at the exact file:line locations listed in D-09.
</objective>
