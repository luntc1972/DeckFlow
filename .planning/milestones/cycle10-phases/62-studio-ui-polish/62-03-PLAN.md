## Trust Boundaries
The panel renders stage names + sanitized per-artifact results to the local operator. No new external
surface; production is read-only (unchanged).

## STRIDE Threat Register
- **Information disclosure (T-62-04, D-07):** the live panel must never surface ex.Message, the DB
  path, the connection string, or the SSH host. Mitigation: append only fixed stage strings +
  `SshDownloadResult` fields; failures keep the existing sanitized copy; bUnit asserts no leak.
- **Integrity (T-62-05):** the progress view must not add a prod write path. Mitigation: display-only
  state; the reader/downloader calls are unchanged except the progress sink (read path).
- **DoS (T-62-06):** an enormous pull could grow `_progressLog` unbounded. Mitigation: cap the list
  to the last N lines.
