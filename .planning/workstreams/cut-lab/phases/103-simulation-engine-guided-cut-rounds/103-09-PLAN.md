| endpoint JSON → DOM | Response fields (card names, banners) are injected into the DOM; must use textContent, not innerHTML, to avoid DOM-based XSS. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-09-01 | Tampering (DOM XSS) | Patching response card names/labels into the proposal card | mitigate | Patch via `textContent`/`createElement`, never `innerHTML` with response strings; class names are code-controlled constants. |
| T-103-09-02 | Denial of Service | Hung request blocking the UI | mitigate | `AbortController` 3s hard cap re-enables the buttons; inline spinner never blocks the whole page. |
| T-103-09-03 | Spoofing | Direct POST bypassing the UI | mitigate | Server-side `SameOriginRequestValidator` + feature gate (Plan 103-07) is the authoritative guard; the TS layer is convenience only. |
