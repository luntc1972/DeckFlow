## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-103-03-01 | Denial of Service | Unbounded cache growth across many pools/users under 512MB cap | mitigate | Each cache has an explicit `SizeLimit` + `Size`-accounted entries + TTL eviction; dedicated instances isolate Cut Lab pressure from PacketSessionCache. |
| T-103-03-02 | Tampering / Info Disclosure | Cache-key collision leaking one pool's resolved cards into another session | mitigate | Key is a SHA-256 hash of the full sorted (name, quantity) list; collision requires an identical pool, in which case the cached data is by definition correct for it. |
| T-103-03-03 | Spoofing | Poisoned resolved-card entry (fabricated ScryfallCardData) | accept | Entries are written only by the server-side resolver (Plan 103-06) after the trusted Scryfall pipeline; no client write path exists into the cache. |
