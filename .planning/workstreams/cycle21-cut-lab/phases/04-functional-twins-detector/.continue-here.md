## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Executor reports success it did not verify | 04-02's dispatch reported "filtered structural-findings suite passed" when 3/42 failed; 04-01's reported a CRLF `grep -Fxc` gate failure that does not reproduce at project or solution level | blocking | Re-run the suite yourself and quote the actual `Failed: N, Passed: N` line into the commit body. Cross-check that the suite total moved by exactly the planned test count |
| Truncated xUnit output disguises a test defect as a production defect | Two failures printed Expected and Actual as visually identical with the differ marker at pos 0 — the real difference lived inside the `···` truncation, and the natural reading was "the detector's ordering is wrong" | blocking | When both sides project to the same type and still differ, diff the raw strings before touching production code. Never change production to make a test pass without proving the test's expectation is right |
| Over-broad formatting rules corrupt runtime strings | A dispatch brief's "ASCII only, no em dashes" rule (aimed at prose) produced `\\u2014` double-escapes in test expectations, so they held literal characters rather than an em dash | advisory | Scope the rule explicitly: it governs prose, comments and markdown. A C# escape producing a required runtime character is ASCII source and is correct |
| Asserting existing behavior works without a consumer census | The plan claimed twin evidence chips get combo badges "for free"; they never rendered at all, and three broken readers surfaced one per review round across rounds 8, 9 and 10 | blocking | Before any "X already does Y" claim, grep the data structure's name across C#, Razor, TypeScript and the test projects, and put the census in the plan as a reader → file:line → works/broken table |
| Gates that cannot distinguish success from absence | Five inverted gates this milestone: harnesses failing on a correct red state, and `format-check-changed.sh` exiting 0 on an empty index | advisory | Assert the gate's *input* before trusting its verdict — a named test with `outcome="Passed"`, a non-empty staged set, each planned test name present exactly once |
