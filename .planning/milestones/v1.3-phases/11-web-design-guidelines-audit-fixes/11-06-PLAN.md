<objective>
Land Sweep 6 of the WDG audit: add `<caption>` and `<th scope="col">` semantics to all audit-flagged tables across admin + deck views.

Purpose: Tables in DeckFlow currently render `<th>` cells without `scope` attributes and lack `<caption>` elements describing their purpose. Screen readers cannot announce table context, and SR users hear cell values without knowing which column they belong to. WDG-06 sweep makes all admin and result tables expose `<caption>` (visible or `sr-only`) and `<th scope="col">` per HTML5 + WAI-ARIA practice.

Output: Six Razor views updated with caption + scope=col additions at the exact file:line ranges from FINDINGS.md.
</objective>
