<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| DeckFlow.Web → archidekt.com | Outbound crawl of an untrusted external JSON API |
| operator-supplied profile URL → outbound request | D-01 manual-URL fallback is operator input that becomes an HTTP target |
| crawler → creator_deck_cache | Crawled external data persisted (must not reach the corpus baseline) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-95-06-01 | Denial of Service (malformed/oversized payload) | Archidekt JSON responses / >105-card decks | mitigate | Bounded `JsonDocument.Parse`; drop `Size > 105` before fetch; each deck fetch flows through Polly (retry/timeout) not raw HTTP |
| T-95-06-02 | Tampering/Elevation (SSRF) | manual profile-URL fallback | mitigate | `ArchidektOwnerUrl.TryGetUsername` rejects any non-archidekt.com absolute URL before it is used to build a request; tested with a link-local target |
| T-95-06-03 | Denial of Service (unbounded pagination) | `next`-followed deck-list loop | mitigate | Hard MaxPages/MaxDecks ceiling; never trust `next` unconditionally (mirror ArchidektRecentDecksImporter's `count` cap) |
| T-95-06-04 | Denial of Service (third-party ToS / hammering) | crawl rate | mitigate | Reuse named Polly pipeline + content-hash read-through cache so re-runs do not re-hit Archidekt (CS-04b) |
| T-95-06-05 | Tampering (baseline self-pollution) | creator_deck_cache vs corpus tables | mitigate | Crawler writes only to `creator_deck_cache`; enforced by acceptance grep (Pitfall 3) |
| T-95-06-06 | Injection | username in outbound query | mitigate | RestSharp `AddQueryParameter` URL-encodes; no string interpolation into the URL (V5) |
| T-95-06-SC | Tampering | package installs | mitigate | No new NuGet packages this plan (RestSharp/Polly/System.Text.Json already present) |
</threat_model>
