<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted session JSON → `CutLabIntent` | The Cut Lab working session round-trips through a hidden form field, so the JSON is attacker-controllable by the submitting client |
| crowd category tags → `MatchesCategories` | Category strings originate from third-party deck sites (Archidekt) and are free text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01-01 | Tampering | `CutLabPlanProfile.GenericStrategies` deserialized from client-supplied session JSON | mitigate | Slugs are never used to build a path, URL, or query. Every consumer resolves them through `DeckPlanStrategyCatalog.TryGetBySlug`, which returns false for anything not in the fixed twelve, so an injected slug is discarded rather than echoed. |
| T-08-01-02 | Denial of Service | Unbounded `GenericStrategies` / `CommanderThemes` arrays in session JSON | mitigate | Consumers deduplicate against the fixed catalog before use, bounding effective strategy count at 12. `CutLabPoolValidator`'s existing pool ceiling already bounds the state document; no new unbounded loop is introduced over these lists in this plan. |
| T-08-01-03 | Information Disclosure | Legacy `PrimaryPlan` / `SecondaryPlan` free text retained on the record | accept | The values are the user's own prior input, already stored in their own session, and are not newly exposed by this change. Removal happens in 08-07. |
| T-08-01-SC | Tampering | npm / NuGet installs | mitigate | This plan adds no packages. If one becomes necessary, stop and obtain explicit user approval per CLAUDE.md before installing. |
</threat_model>
