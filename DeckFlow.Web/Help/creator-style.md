# Creator-Style Critique

The Creator-Style Critique page (`/creator-style`) checks how closely your deck matches a selected creator's observed build style. The result is a structured critique packet you can copy into ChatGPT, plus a quick rubric read of where your list is aligned, drifting, or off-plan.

## Step 1 - Pick A Creator

Choose a creator from the dropdown. Each option shows the creator name together with the available evidence depth, so you can tell which profiles are grounded in a broader exemplar set before you run the critique.

## Step 2 - Submit Your Deck

Pick one of two inputs:

- **Public URL** - paste a supported deck link.
- **Paste decklist** - paste your list, one card per line.

Then submit the form to build the critique packet.

## Step 3 - Read The Critique

The result panel gives you:

- **Rubric verdict chips** - fast pass / caution / miss signals for the measured dimensions that define the creator's style.
- **Exemplar deck names** - the specific anchor decks that best represent the style you are being compared against.
- **A ChatGPT-ready packet** - copy the packet as-is when you want a fuller written critique or revision pass.

The packet is written to stay concrete: what your deck is doing now, where it matches the creator, where it diverges, and which dimensions are most worth changing first.

## Degraded States

If the selected creator profile is thin, stale, or temporarily incomplete, the page explains that directly in the result so you know to treat the verdict as lower-confidence. If your submitted deck cannot be read cleanly, the page calls out the input issue instead of giving a misleading style read.

## Notes

- This tool critiques style fit, not raw power level.
- Different creators can reward very different ratios, curve shapes, and card-role mixes, so switching the dropdown can materially change the verdict.
- This tool can be turned off by an administrator; when it is, this help topic is hidden too.
