<objective>
Make the Archidekt harvest skip rewriting a deck's cached category rows when its cards/categories
are unchanged (per-source SHA-256 content hash over the written shape), and re-check a deck only
after 5 days instead of 1. Cuts delete+insert write churn on the ~3.9M-row
`card_category_observations` / ~4.1M-row `card_deck_totals` fact tables while keeping data fresh.

Purpose: Reduce harvest write amplification (a contributor to the suggestion-read pressure addressed
in Phase 24) without changing the read/lookup path. Layers on the Phase 26 normalized integer-keyed
schema; uses the `content_hash` column Phase 26 reserved on `deck_queue`.

Output: A content-hash write gate in the harvest session, repository hash get/set + 5-day cooldown,
a new `Unchanged` telemetry bucket, and Core unit tests proving the unchanged path issues zero fact-table
DML. Implements CAT-02.
</objective>
