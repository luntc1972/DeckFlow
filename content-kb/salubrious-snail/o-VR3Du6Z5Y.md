## Summary

Video on reading EDHRec more critically. Core idea: percent-inclusion stats flatten which deck a card belongs to, so use "indicator cards" — cards disproportionately run in one style — to map the archetypes hiding on a commander's page. Worked examples: For Malcolm, Keen-Eyed Navigator + Francisco, Fowl Marauder, ~58% run the Thassa's Oracle + Demonic Consultation two-card combo (a high-power signal), while ~35% run midrange pirates like Ramirez and Hostage Taker; the presenter treats Thoracle and Ramirez as indicators to build a Venn diagram of combo vs midrange builds. He notes Thoracle's high play rate signals a budget-friendly high-power path (~84 cents). For Skeleton Ship, indicator cards Freed from the Real, Thrummingbird, and Reassembling Skeleton split commander-synergy, proliferate, and skeleton-tribal builds. For Archelos, Lagoon Mystic he separates tap/untap, turtle-tribal, and gates builds, using Baldur's Gate, Nine-Fingers Keene, and Maze's End as gate indicators — he rates Maze's End best and Baldur's Gate worst in three colors. Stated heuristic: don't add cards that merely look good without asking which deck they belong to or how many of a card type fit, or you get a disjointed, clunky mishmash. EDHRec is data, not magic — don't autopilot.
