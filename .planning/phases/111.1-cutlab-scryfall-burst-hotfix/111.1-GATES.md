# Phase 111.1 — Cut Lab Scryfall Burst Hotfix — Regression Gates

Canonical, copy-pasteable gate sequence for this phase. Run the commands in this order. This
artifact IS the SC-6 deliverable: SC-6 is satisfied by an OBSERVED, reproducible green run of both
suites, recorded in Section 3, not merely by the tests existing.

Every git gate below carries an explicit `-- <paths>` scope (round-1 review W-2): plans 01-05 share
one worktree, so an unscoped `git diff --name-only` in one plan's gate can fail because a SIBLING
plan legitimately wrote a `.planning/` artifact, an ADR, or a measurement doc that plan does not own.
Do not "simplify" the scoping away — it is load-bearing for the multi-plan wave, not decoration.
