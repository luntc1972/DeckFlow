<objective>
Detect the Moxfield companion as INERT side metadata (its name only) and thread it to the
manabase service, while keeping importer entry output byte-identical for deck-analysis. Lock
the Archidekt passthrough (Background/Companion stay mainboard with category preserved) with
regression tests so the 72-05 service-layer detection has a stable contract.

Purpose & critical decision: RESEARCH Pattern 4 proposes `AddBoardEntries("companions",
"mainboard")`. We DO NOT do that. The Moxfield companion is outside the 99 today (the
companions board is unread), so injecting it as a mainboard entry would add a card to BOTH
manabase (flag OFF) AND deck-analysis output, breaking byte-identity (SPEC §B/§C/§G: companion
is "outside-the-99" and "side metadata only, no Board remap, no global importer output change").
We extract the NAME only; the manabase service (72-05, flag ON) resolves + models it separately.
Output: DetectedCompanionName plumbed through; Archidekt passthrough regression-locked.
</objective>
