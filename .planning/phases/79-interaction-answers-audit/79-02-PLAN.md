<objective>
Surface the Phase 79 interaction audit into the /deck-analysis PASTE ARTIFACT: gate it behind the new
`analysis.interaction-audit` flag (seeded OFF in both dialects), compute the audit once from the already-
resolved current-deck card references, format a hedged card-backed block, and thread that block string
into all three decoupled prompt variants (ChatGpt/Claude/Gemini) with no shared helper.

Purpose: INTERACT-03 requires the flag + seed + 3-variant parity; INTERACT-01/02 require the bucketed,
card-backed, gap-flagged, hedged content in the artifact the user pastes. This is the exact Phase-77
multi-axis-score recipe (flag gate → block-text builder → 3 variants → parity test) applied to the
interaction audit.
Output: catalog + seed rows, a flag gate + `BuildInteractionAuditText`, three variant insertions, a
3-platform parity test, and an extended seed-consistency assertion.
