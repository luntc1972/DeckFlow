## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| harvested transcript text -> KB artifact -> scorer input | Third-party YouTube caption text (untrusted) is read from artifact `.md` files into ScoreInput.SearchText. This plan only SCORES/SELECTS that text; it does not yet render it to the LLM prompt (KBR-03, Plan 02 handles the injection-path fence/sanitizer). |
| commander name (deck input) -> text-side substring/regex match | Commander name is user-supplied and used in ContainsCommanderName and (new) known-commander matching. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-01 | Tampering | Adversarial transcript text influencing SELECTION (e.g. stuffing the deck's archetype terms to force a clip in) | accept | Out of scope for selection; selection only ranks clips, it does not execute them. The injected text is fenced + sanitized at the prompt boundary in Plan 02 (KBR-03) before reaching any LLM. Residual: a crafted transcript could rank higher, but it cannot act as an instruction at selection time. |
| T-34-02 | Denial of Service | Known-commander text scan / content-overlap tokenization over clip text per row | accept | Corpus is ~82 visible rows; tokenization is O(n) per row over already-read text. PITFALLS performance note: pre-compute mentioned_commanders only needed at >500 clips. No new per-request I/O. |

No SQL is issued in this path. |
| T-34-SC | Tampering | npm/pip/cargo installs | mitigate | NONE expected. This plan adds zero dependencies (locked decision: algorithmic, zero-dep). If any package install is proposed, STOP — it is a scope violation per CLAUDE.md + 34-CONTEXT. No package-manager command runs in this plan. |
