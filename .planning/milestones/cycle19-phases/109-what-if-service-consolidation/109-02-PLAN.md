# Plan 109-02 — Both Transports Adopt TryValidateSwap + CommitSwapAsync and Migrate Duplicate Tests

<objective>
Flip all four what-if pair-validation call sites onto the shared `ICutLabWhatifService` (built in 109-01): both PREVIEW paths pre-validate via `TryValidateSwap`, and both COMMIT paths derive their swap outcome from `CommitSwapAsync`. Delete the two duplicated restore-then-accept blocks and both divergent validation helpers (`ValidateWhatifPair`, `IsValidWhatifPair`), and preserve each transport's downstream projection and error behavior exactly. Then migrate the duplicated controller-level business-rule tests into the shared service tests (already added in 109-01), leaving only thin delegation/HTTP-shape tests, preview-invalid regression tests, and the two pitfall negatives at the controller level. This is a behavior-preserving refactor: no new user-facing behavior, and every existing endpoint protection and error path stays observable.

This plan is structured as two atomic vertical slices — one per transport — so each task keeps the full suite green on its own commit (code + its own test migration land together; the old controller business-rule tests would otherwise break the moment their controller delegates to the fake service). Task 1 owns the API transport end-to-end; Task 2 owns the no-JS transport end-to-end and closes the cross-controller grep gate once BOTH helpers are gone.

Purpose: CLUP-04/CLUP-05 — both transports route validate + commit through the one service so the rules cannot drift (across transport OR across preview/commit), and the tests stop duplicating those rules per controller.
Output: Two consolidated controller commit paths, two consolidated preview pre-checks, both private validators deleted, and de-duplicated test files.
</objective>

<execution_context>
Delegation: per project rules Codex writes the implementation; this plan is executor-agnostic but implementation-ready. This plan deletes code from long controller methods — remove exactly the duplicated block and helper, leaving the rest of each file byte-for-byte identical.

Green-between-waves discipline: within each task, add the preview-invalid regression tests and wire the preview path to `TryValidateSwap` BEFORE deleting that transport's private helper, so the characterization coverage exists before the deletion lands. Each task's `verify` runs the migrated test set and must exit 0.
</execution_context>
