<objective>
Rename every `chatgpt-*` CSS identifier — 39 class stems (~1553 refs) plus 4 attribute selectors —
to `prompt-*` across all 25 theme fork files and the shared CSS (site.css / site-common.css /
site-commander-table.css / site-mobile.css / site-theme-overrides.css), satisfying AICLEAN-01. This
is a pure mechanical stem-preserving rename (`.chatgpt-<stem>` -> `.prompt-<stem>`,
`[data-chatgpt-<x>]` -> `[data-prompt-<x>]`) with byte-identical rendered output — NO declaration,
value, color, selector-order, or specificity change.

Purpose: the `chatgpt-*` CSS names brand generic prompt-tool UI chrome after one AI model; renaming
to `prompt-*` makes them AI-agnostic. All 39 stems are confirmed generic UI chrome (RESEARCH CSS
Inventory), none tied to a specific AI model — this is the D3-clean subset (no keep-list items live
in CSS).
Output: 25 edited CSS files; zero `chatgpt` remaining in css/; token-normalized diff EMPTY (only
identifier tokens changed); build 0/0; render proven byte-identical in plan 85-05 against the 85-01
baseline.

NOTE: this plan renames CSS selectors only. The matching Razor `class="chatgpt-*"` emissions and
deck-sync.ts `querySelector('.chatgpt-*')` consumers are renamed in plans 85-03/85-04 in the SAME
wave (wave 2). Render is byte-identical at the WAVE boundary (proven by 85-05), not necessarily at
each intra-wave commit — a CSS-renamed-but-Razor-not intermediate would transiently orphan a
selector; this is expected and resolved when the wave completes. Build + xUnit stay green per
commit regardless (CSS is not compiled; view-render tests assert emitted HTML, updated in 85-03).
</objective>
