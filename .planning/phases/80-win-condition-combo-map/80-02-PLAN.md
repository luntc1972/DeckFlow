<objective>
Surface the Phase 80 win-condition/combo map into the /deck-analysis PASTE ARTIFACT: gate it behind the
new `analysis.wincon-map` flag (seeded OFF in both dialects), REUSE the single already-wired combo fetch
(widen its gate — no second call), map the cached `CommanderSpellbookResult` + current-deck card refs onto
the Core input DTOs, compute the map once, format a hedged block, and thread that block string into all
three decoupled prompt variants (ChatGpt/Claude/Gemini) with no shared helper.

Purpose: WINCON-04 requires the flag + seed + 3-variant parity; WINCON-01/02/03 require the enumerated
ranked combos + near-combos + assembly count + band + data-unavailable disclosure + closing cards in the
artifact the user pastes. This is the exact Phase-79 interaction-audit recipe (flag gate → block-text
builder → 3 variants → parity test) applied to the win-con map, with one addition: widening the SINGLE
combo gate so the already-cached result is reused (never re-fetched).
Output: catalog + seed rows, a `WinConMapFlag` gate + `CommanderSpellbookResult`→Core mapping +
`BuildWinConMapText`, three variant insertions, a 3-platform parity test, and a seed-consistency assertion.
</objective>
