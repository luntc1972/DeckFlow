Install the DeckFlow Bridge extension

Browsers do not allow this site to install the extension automatically. Download it, load it unpacked, then return to DeckFlow and retry the import.

Download the DeckFlow Bridge (.zip)

Current status

Load-unpacked only for now — no Chrome Web Store listing yet.

The DeckFlow bridge uses an allowed-origins list in the extension settings. Version 0.1.1 and later ship with deckflow.gg and localhost already allowed, so the public site works out of the box. Only add an origin manually if you run DeckFlow on some other host.

Install steps

  1. Click Download above to save deckflow-bridge.zip.
  2. Unzip it anywhere on your machine.
  3. In Chrome or Edge, open chrome://extensions.
  4. Turn on Developer mode.
  5. Click Load unpacked.
  6. Select the unzipped deckflow-bridge folder.
  7. On the public deckflow.gg site this is all you need. If you run DeckFlow on another host, open the extension's details page → Extension options and add that origin to the allow list.
  8. Return to DeckFlow and submit the Moxfield URL again.

What it does

The DeckFlow Bridge fetches the Moxfield deck in your logged-in browser session when the DeckFlow server cannot reach it directly, then hands the deck data back to DeckFlow so the normal import flow can continue.

The bridge injects broadly, but it only responds to origins you explicitly allow in extension options.
