<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Operator paste input → YoutubeExplode | Channel URL/handle and video URL/ID strings are untrusted input parsed before any HTTP call |
| Blazor circuit → background Task.Run | Long-running IO crosses off the SignalR sync context; cancellation and render marshalling must follow the circuit lifecycle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-06 | Tampering | Video URL/ID paste queue | mitigate | All IDs/URLs are resolved through `IYouTubeChannelVideoLister.GetByIdsAsync` (YoutubeExplode VideoId.TryParse) which validates before any HTTP call and throws ArgumentException on bad input; the page catches it and shows a user error instead of crashing. |
| T-45-07 | Spoofing (SSRF) | Channel URL input | accept | All outbound HTTP goes through YoutubeExplode (trusted lib, YouTube-only); Studio binds localhost-only and is single-operator (no public endpoint). |
| T-45-08 | Denial of service | Blazor circuit blocking / AngleSharp concurrency | mitigate | Orchestrator + lister calls run inside Task.Run (Pitfall 1); a single `_operationInFlight` lock plus no `Task.WhenAll` over the lister prevents concurrent AngleSharp use (Pitfall 2); CTS disposed on Dispose stops orphaned work on circuit drop. |
| T-45-18 | Denial of service / crash | Post-Dispose progress callback (disposal race) | mitigate | The progress sink marshals both `_logLines.Add` and `StateHasChanged` through InvokeAsync and wraps them in a try/catch that swallows ObjectDisposedException / disposed-renderer InvalidOperationException, so a callback firing after the circuit drops drops silently rather than raising an unobserved exception that could fault the host. |
| T-45-09 | Information disclosure | Page + log output | mitigate | The page renders only video metadata and progress text; it logs no connection string, provider value, or ledger key. Verified in the human-verify checkpoint step 7. |
| T-45-SC | Tampering | npm/pip/cargo installs | accept | No package installs; Bootstrap/Open Iconic already bundled; no new NuGet (CLAUDE.md). |
</threat_model>
