## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| research artifact -> CLI | Git-committed JSON, operator-run, offline. Not reachable from any HTTP path. |
| CLI -> committed snapshot | The one write in this plan. A bad write ships wrong floors to every Cut Lab user on the next deploy. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-05 | Tampering | A corrupt regeneration overwriting the committed snapshot | mitigate | Task 1 evaluates drift before `Directory.CreateDirectory` and before any `File.WriteAllText`; Task 3 demonstrates the refusal empirically and asserts the committed file is byte-identical afterwards. |
| T-03-06 | Tampering | A silently disabled guard from a typo in the thresholds file | mitigate | Every threshold is `required`, so `FromJson` throws; Task 3 check 1 proves the command exits non-zero rather than defaulting. |
| T-03-07 | Tampering | A mean-only EDHREC row entering a percentile floor | mitigate | Task 1's source guard rejects any non-`postgres` row in the six adopted roles before `Build` runs; Task 3 check 3 proves it. |
| T-03-08 | Information Disclosure | Public repo receiving a new committed data file | accept | The snapshot carries commander names, sample counts, and integer role floors — all derived from Phase 2's already-committed public findings. No credentials, no PII. The Postgres connection string is never read by this command. |
| T-03-09 | Denial of Service | A malformed shipped snapshot crashing the web app at startup | transfer | Handled by plan 03-03's fail-open provider, which mirrors `CedhLandBaselineProvider`'s catch set. Not this plan's boundary. |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs. `git diff -- '*.csproj' | grep -c PackageReference` must return 0; adding any dependency requires explicit user approval per CLAUDE.md. |
