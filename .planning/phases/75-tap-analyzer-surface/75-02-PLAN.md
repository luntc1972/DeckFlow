<objective>
Implement the actual tap-quality computation inside the existing manabase pipeline, turning the Wave 0 Core/TextBuilder behavior tests GREEN. No new simulation pass — a single per-trial bit plus an averaging step, exactly per TAP-03.

Purpose: Surface the two metrics the simulator already implies (untapped composition + turn-1 availability) without changing any existing castability/health number.

Output: A `hadUntappedT1` observation accumulated into `CardCastability.Turn1UntappedTrials`; a `ComputeTapAnalysis` step in `ManabaseAnalyzer.Analyze` that builds `ManabaseReport.TapAnalysis`; and an "Untapped Sources:" section in `ManabaseReportTextBuilder` emitted only when `tap` is non-null.

Honors locked decisions from 75-01: average turn-1 across NON-COMMANDER rows (fall back to all rows if none); composition denominator = all colored sources via `EffectiveSources` weighting; turn-1 metric is deck-level "≥1 untapped source on turn 1."
</objective>
