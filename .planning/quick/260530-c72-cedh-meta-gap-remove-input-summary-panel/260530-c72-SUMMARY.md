# Quick Task 260530-c72 — Summary

## What changed

1. **Removed on-screen Input Summary panel** (`CedhMetaGap.cshtml`, Step 2). Deleted the
   `@if (...Model.InputSummary) { <section class="summary-panel">...<pre> }` block. It was a
   redundant echo of the filters + reference-deck list (both already shown in the reference
   table below and saved in the `.zip` session). `Model.InputSummary` and
   `MetaGapService.BuildInputSummary` are UNCHANGED — still built and serialized into the
   downloadable session artifact.

2. **Mobile-friendly reference table.** The 9-column "EDH Top 16 References" table overflowed
   on phones (headers wrapped char-by-char: "Sel ect", "Par tici pan ts", "De ckl ist").
   - Added `data-label="..."` to each `<td>` (Select, #, Player, Date, Participants, Finish,
     W-L-D, Win %, Decklist).
   - Added a `@media (max-width: 600px)` rule in `site-common.css` scoped to
     `table[data-chatgpt-cedh-reference-table]`: header row sr-only-hidden, each row becomes a
     bordered card, each cell becomes a flex row with its `data-label` as the left field name
     and the value right-aligned. Uses existing theme tokens (`--line`, `--muted`).

## Mobile card refinements (post-UAT iteration, 2026-05-30)

Initial stacked layout (`space-between` rows) reviewed live + against Web Interface
Guidelines + Adrian Roselli's responsive-accessible-table guidance. Iterated to:

- **Card with header band** — checkbox + `#rank` + player on one row; remaining fields
  as a tight label:value grid (fixed 6.5rem label column, value left-aligned right
  after — closes the label↔value gap from the first cut).
- **A11y — table semantics preserved.** Added `role="table"/rowgroup/row/columnheader/cell`
  to the markup. The `<=600px` `display:grid` override otherwise strips a table's
  screen-reader semantics (Roselli 2017); the roles restore them (redundant-but-harmless
  on the desktop table).
- **A11y — checkbox name.** `aria-label="Select reference deck #N — Player"` (was a
  nameless checkbox).
- **Touch targets (WIG).** Checkbox enlarged to 1.35rem; "Open" decklist link given a
  min tap height; both `touch-action: manipulation`.
- **Selected-state.** `tr:has([data-chatgpt-cedh-reference-checkbox]:checked)` → accent
  border + 1px ring (mobile-only, per user) for the pick-1-to-3 affordance.
- **Border bleed fix.** Zeroed the base `.conflicts-table` cell borders inside the mobile
  scope — they were rendering as stray partial lines through the card grid; the single
  intended divider is re-added under the header band.

All scoped to `[data-chatgpt-cedh-reference-table]`; DeckSync / CommanderCategories
tables remain untouched. Visually confirmed by the user at ~390px across multiple cards.

## Reference-table sort + desktop fix (2026-05-30, server stopped for tests)

Live desktop review surfaced three more issues; addressed together:

- **Sort bug (C#).** `MetaGapService` always re-sorted fetched entries newest-first,
  ignoring `request.SortBy` — the Top/Recent dropdown changed nothing visible.
  Extracted `OrderEntries`: TOP = best finish first (Standing asc, win-rate tiebreak),
  NEW = most recent first. Added a regression `[Theory]` (NEW→"Recent" first, TOP→
  "Winner" first); pinned the existing prompt-assembly test to `SortBy=NEW` so its
  date-desc expectation is explicit, not default-dependent.
- **Client-side sortable columns (TS feature).** In-cell `<button>` per sortable header
  (#, Player, Date, Participants, Finish, Win %) with `aria-sort` + a direction glyph.
  `deck-sync.ts#sortChatGptCedhReferences` sorts rows by `data-sort-value` (numeric vs
  locale string), re-appends, and re-numbers `data-chatgpt-cedh-page` so pagination
  follows the new order. Dropdown (server sort) kept. JS is build-output (gitignored;
  Docker `tsc` regenerates) — only the `.ts` source is committed.
- **Desktop header char-wrap.** `white-space: nowrap` on the reference-table `th`.
