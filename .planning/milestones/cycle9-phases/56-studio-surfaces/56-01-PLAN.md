ContentSiteIndexRow (DeckFlow.Core/Knowledge/ContentArtifactSpec.cs):
- DateTimeOffset? PushedToProdUtc   // Phase 55; null = never pushed to prod
- bool IsVisible                    // set by site admin, not by push
- string ApprovalStatus             // "pending" | "approved" | "rejected"

Resolution order (first match wins) — see 56-RESEARCH.md §8:
1. IsBlockedAsync                         -> Blocked
2. GetByNaturalKeyAsync (index row found):
   a. PushedToProdUtc != null && IsVisible -> Published
   b. ApprovalStatus == "approved"         -> Approved
   c. else                                 -> Distilled
3. GetVideoByYoutubeIdAsync on enabled sources -> Harvested
4. else                                         -> NotHarvested
</interfaces>
