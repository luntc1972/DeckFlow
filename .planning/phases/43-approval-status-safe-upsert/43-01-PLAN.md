<objective>
Add the data-layer prerequisites for the v1.7 review/publish workflow, all in DeckFlow.Core, with no UI and no publish/commit/SCP logic:

1. An `approval_status` column on `content_site_index` (`pending`/`approved`/`rejected`), added via the established self-healing ALTER pattern, with DDL-level `DEFAULT 'pending'` and a self-guarded grandfather backfill (REVQ-01).

3. `GetApprovedRowsAsync` (approved-only filtered read) plus wiring the orchestrator export to it, and wiring the distill index-write to the safe overload (PUB-02 + D-09).

These compile-fix stubs are the deliberate EXCEPTION to "tests live only in Plan 02" — Plan 02's wave-2 integration tests cannot compile unless the solution already builds.
