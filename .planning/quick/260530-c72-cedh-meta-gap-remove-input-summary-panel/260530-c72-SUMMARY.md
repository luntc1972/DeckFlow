# Quick Task 260530-c72 — Summary

## What changed

1. **Removed on-screen Input Summary panel** (`CedhMetaGap.cshtml`, Step 2). Deleted the
   `@if (...Model.InputSummary) { <section class="summary-panel">...<pre> }` block. It was a
   redundant echo of the filters + reference-deck list (both already shown in the reference
   table below and saved in the `.zip` session). `Model.InputSummary` and
   `MetaGapService.BuildInputSummary` are UNCHANGED — still built and serialized into the
   downloadable session artifact.

2. **Mobile-friendly reference table.** The 9-column "EDH Top 16 References" table overflowed
   on phones (headers wrapped char-by-char: "Sel ect", "Par tici pan ts", "De ckl ist").
   - Added `data-label="..."` to each `<td>` (Select, #, Player, Date, Participants, Finish,
     W-L-D, Win %, Decklist).
   - Added a `@media (max-width: 600px)` rule in `site-common.css` scoped to
     `table[data-chatgpt-cedh-reference-table]`: header row sr-only-hidden, each row becomes a
     bordered card, each cell becomes a flex row with its `data-label` as the left field name
     and the value right-aligned. Uses existing theme tokens (`--line`, `--muted`).

## Scope safety

  CommanderCategories is untouched.
- Layout CSS placed in `site-common.css` (not `site.css` / theme forks), per CLAUDE.md.
- LF endings preserved; only the necessary lines touched; no reformatting.
