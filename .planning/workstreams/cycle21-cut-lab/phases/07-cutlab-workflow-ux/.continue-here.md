## Method rules this phase paid for

- **Never A/B with a git worktree.** `playwright.config.ts` sets `reuseExistingServer` true under
  WSL, so a baseline worktree silently reuses a HEAD server on `:5173`. Use
  `git checkout --detach`, confirm `curl :5173` returns `000`, and rebuild.
- **A running dev server does not track the tree.** Grep the served `/js/cut-lab.js` for the
  expected string **and** assert the old one is absent before believing any UI result.
- **One spec, one project, one process, `--workers=1`**, clearing `/tmp/deckflow-admin-e2e.lock`
  first. Batched runs manufacture false failures via admin-lock contention (3 of them here).
- **A single run cannot A/B a flaky test.** n=1 per side is not evidence.
- **Never diff two capped failure lists.** A/B by running the ONE suspect spec alone per side.
- **Bare `git status`, not a path-filtered one**, before reasoning about who changed what — a
  `-- DeckFlow.Web/` filter hid four files and looked like a concurrent writer that did not exist.
- Gate verdicts come from the **process exit code**, not the printed footer — the gate spec is
  `mode: 'serial'` and reports post-failure tests as "did not run", which skims as a pass.
- **Workstream trap:** phases live under `.planning/workstreams/cycle21-cut-lab/phases/`. `gsd-tools`
  queries need `--ws cycle21-cut-lab` or they silently answer from the root roadmap.
