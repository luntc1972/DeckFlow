<objective>
Build the two largest content stores in `DeckFlow.Web/Services/Content`: `ContentSourceStore` (owns `content_sources`, KB-01) and `ContentVideoStore` (owns the videos aggregate — `content_videos` + `content_transcripts` + `content_summaries` + `content_clips` + `content_tags`, covering KB-04 transcript persistence + KB-07 tag schema). Each copies the `HarvestRunStore`/`FeatureFlagStore` dual-DDL + SemaphoreSlim schema-gate skeleton verbatim and opens connections through the new central `OpenConnectionAsync` so SQLite FK CASCADE actually fires. This plan delivers the D-04 CASCADE proof test — the load-bearing verification that the entire FK design is real, not a documentation lie — and proves it across ALL FOUR child tables (REVIEW #6).

Because `content_videos.source_id REFERENCES content_sources(id)`, the parent table must exist before the child DDL runs (REVIEW #1, HIGH — Postgres rejects an FK to a missing parent). ContentVideoStore therefore ensures content_sources first.

Purpose: Materialize the source + video persistence aggregate with provably-firing CASCADE integrity across every child table and correct parent-first bootstrap ordering.
Output: 2 store interfaces + 2 store classes + 2 Web.Tests files.
</objective>

content_sources: id PK, source_slug TEXT NOT NULL, display_name TEXT NOT NULL,
  source_type TEXT NOT NULL CHECK(IN 'youtube_channel','podcast_rss'), source_url TEXT NOT NULL,
  is_enabled BOOL NOT NULL DEFAULT TRUE, created_utc TS NOT NULL DEFAULT now(),
  UNIQUE(source_url), UNIQUE(source_slug)   -- slug feeds artifact paths; collision = path collision (REVIEW #5)
content_videos: id PK, source_id -> content_sources(id) ON DELETE CASCADE, youtube_video_id TEXT NULL,
  rss_guid TEXT NULL, title NOT NULL, video_url NOT NULL, published_utc TS NULL,
  transcript_status TEXT NOT NULL DEFAULT 'pending' CHECK(IN 'pending','captions','whisper','failed','skipped_over_cap'),
  created_utc TS NOT NULL DEFAULT now(), UNIQUE(youtube_video_id), UNIQUE(rss_guid),
  CHECK (youtube_video_id IS NOT NULL OR rss_guid IS NOT NULL)   -- every video has >=1 natural key (REVIEW #5)
content_transcripts: id PK, video_id -> content_videos(id) ON DELETE CASCADE,
  source TEXT NOT NULL CHECK(IN 'captions','whisper'), body NOT NULL, created_utc TS NOT NULL DEFAULT now()
content_summaries: id PK, video_id -> content_videos(id) ON DELETE CASCADE, body NOT NULL, created_utc TS NOT NULL DEFAULT now()
content_clips: id PK, video_id -> content_videos(id) ON DELETE CASCADE, timestamp_s INT NOT NULL, excerpt NOT NULL, sort_order INT NOT NULL DEFAULT 0
content_tags: id PK, video_id -> content_videos(id) ON DELETE CASCADE,
  dimension TEXT NOT NULL CHECK(IN 'archetype','bracket','card_category'), tag_value TEXT NOT NULL, UNIQUE(video_id,dimension,tag_value)

<type_mapping>
Postgres -> SQLite:
- BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY -> INTEGER PRIMARY KEY AUTOINCREMENT
- BIGINT (FK col) -> INTEGER
- TIMESTAMPTZ NOT NULL DEFAULT now() -> TEXT NOT NULL DEFAULT (datetime('now'))
- TIMESTAMPTZ NULL -> TEXT NULL
- BOOLEAN NOT NULL DEFAULT TRUE -> INTEGER NOT NULL DEFAULT 1
- REFERENCES parent(id) ON DELETE CASCADE -> identical syntax (fires only with PRAGMA foreign_keys=ON)
- CHECK (x IN (...)) -> identical
- CHECK (col_a IS NOT NULL OR col_b IS NOT NULL) -> identical
</type_mapping>
