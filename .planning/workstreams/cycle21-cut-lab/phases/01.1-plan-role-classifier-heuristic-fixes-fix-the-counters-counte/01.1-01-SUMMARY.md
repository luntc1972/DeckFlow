# 01.1-01 Summary

## Outcome

Plan `01.1-01` landed in two commits:

- `test(01.1-01): add failing tests for Counters/counterspell tag collision`
- `fix(01.1-01): stop Counters synergy tag matching the counterspell arm`

`PlanRoleClassifier.FromCategories` now treats the plural counters-synergy sense as non-interaction in both modes while preserving the existing cEDH-only interaction behavior for genuine counterspell vocabulary (`Counterspell`, `Counterspells`, `Counter`, `Counter Magic`, `Countermagic`, `Counter-magic`).

## Known Behavior Change

This is an intended, user-visible Cut Lab output change: `CutLabStructuralFindings.ComputeStrandedSubthemes` uses `PlanRoleClassifier.CategoryMapsToPlanRole(theme.Key)` to exclude plan-role themes from stranded-subtheme findings. Before this fix, a theme named `Counters` was wrongly excluded because it collided with the counterspell classifier arm. After this fix, a small `Counters` theme is eligible to appear as a `StrandedSubtheme` finding. That is intended behavior, not a regression.
