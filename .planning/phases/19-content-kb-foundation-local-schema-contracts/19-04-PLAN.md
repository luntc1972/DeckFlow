## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Store SQL → SQLite/Postgres | DDL + DML injection surface |
| env DECKFLOW_WHISPER_MONTHLY_CAP_USD → cap value | Operator-controlled; the only cap source (not DB), single-user local model |
| content_site_index → Render Postgres | The ONLY data crossing to the hosted environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-19-11 | Tampering (SQL injection) | All 3 stores' parameterized queries | mitigate | Every value via `RelationalDatabaseConnection.AddParameter`; zero string-concatenated SQL |
| T-19-12 | Information Disclosure | transcript/spend/audio data leaking to Render | mitigate | content_site_index carries NO transcript/cost/audio columns (D-14); acceptance grep proves their absence; whisper_spend_ledger + transcripts stay in local content-kb.db only |
| T-19-13 | Tampering / integrity | Spend cap bypass or wrong cap | accept | Cap lives in env (DECKFLOW_WHISPER_MONTHLY_CAP_USD), operator-controlled — acceptable for single-user local model (D-08/D-09). No TOCTOU lock by design; stub is inert in Phase 19 (no Whisper calls) |
| T-19-14 | Elevation of Privilege | absolute path in artifact_path enabling traversal | mitigate | D-12: store RELATIVE artifact_path only; store performs no absolute-path construction; Phase 22 resolves against MTG_DATA_DIR |
| T-19-15 | Denial / schema collision | content_harvest_runs colliding with harvest_runs | mitigate | content_ prefix; separate ContentHarvestRunStore class; acceptance grep proves no bare `harvest_runs` CREATE |
| T-19-SC | Tampering | npm/pip/cargo installs | n/a | No package installs; existing Sqlite/Npgsql only |
</threat_model>
