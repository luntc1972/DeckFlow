<objective>
Add the deploy-confirm surface D-09 (REVISED) requires: a small AUTHENTICATED, read-only web endpoint `GET .../contentkb/deployed-body-hash?naturalKeyType={t}&naturalKeyValue={v}` that resolves the row's artifact from the git `/app` tree ONLY, returns 404 if that artifact is missing, and otherwise returns JSON `{ bodySha256 }` recomputed with the shared `ComputeBodySha256` helper. Studio's confirmer (Plan 90-05) polls this until `200 && bodySha256 == expected` before DirectPush stamps/flips visibility.

Purpose: Codex plan-review proved the original "GET the public detail page → 200" confirm was unsound (a not-yet-visible row 404s forever; a missing artifact renders a 200 shell → false confirm; an updated visible row returns the OLD body's 200 before Render deploys → stale confirm; local-vs-prod id mismatch makes the URL unbuildable). A dedicated /app-only, is_visible-independent, natural-key, hash-returning endpoint defeats all four races via hash-match.
Output: the endpoint controller, a git-/app-only resolver method, and web tests (present→200+hash, missing→404, hidden-independent, auth-required).
</objective>

| natural-key + artifact path -> /app filesystem read | caller-supplied key/path resolved against the git tree |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-90-16 | Information Disclosure / EoP | endpoint is a targeted /app file-read primitive | mitigate | Routed under `/Admin` so the existing BasicAuthMiddleware gate authenticates it; reuses `ContentKbArtifactPathResolver` safe-path/containment (git-only method); reads only within the content-kb root; returns a hash, not file contents. |
| T-90-17 | Tampering (SameOrigin bypass misuse) | omitting SameOriginRequestValidator | accept (by design) | D-09 REVISED: Studio->prod has no browser Origin, so SameOrigin would wrongly reject it; BasicAuth is the actual auth boundary. | T-90-18 | Path traversal | naturalKeyValue / ArtifactPath into the resolver | mitigate | Resolution goes through `TryResolveGitArtifact` -> `IsSafeArtifactPath`/containment; a non-`content-kb/` or uncontained path -> NotFound, never a read outside the root. |
| T-90-SC | Supply chain | package installs | mitigate | No new packages — existing store/resolver/BCL SHA-256. No install step. |
