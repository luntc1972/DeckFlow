</objective>

NO double-`content-kb`. This decision is fixed BEFORE both Wave-2 plans run (it does not depend on this plan's runtime output) — that removes the Plan 03→Plan 02 data dependency the review flagged (HIGH-1). The SUMMARY still RECORDS the realized base for traceability, but Plan 03 binds to `ContentRootPath` per this locked decision, not to a value discovered at this plan's runtime.
