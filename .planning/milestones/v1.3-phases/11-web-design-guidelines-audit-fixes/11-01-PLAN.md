  <action>
    Add the following five rule blocks to `DeckFlow.Web/wwwroot/css/site-common.css`. Use existing comment-banner / section conventions already present in the file. Per D-07 these are the ONLY CSS edits in Sweep 1 — do NOT touch site.css, admin.css, or any theme fork.

    1. On the existing `:root` selector (or add a new `:root` block at top if conventional placement differs), declare `color-scheme: light dark;`. This signals user-agent that native form chrome / scrollbars should follow the page's intent. Per finding O.

    2. Add a global `@media (prefers-reduced-motion: reduce)` block that neutralizes animation across the app. Set `animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; scroll-behavior: auto !important;` on `*, *::before, *::after`. Per W3C convention use `0.01ms` (per Claude's Discretion note in CONTEXT.md). Per finding P, this generalizes the narrow `site.css:1373-1383` block (which only gated `.busy-indicator__spinner` + `.hub-card`) into an app-wide gate. Do NOT remove the existing block in site.css — that is out of scope; just supersede via the broader site-common.css rule.

    3. Add `button, a, summary { touch-action: manipulation; }` to remove the 300ms tap delay on touch devices. Per finding Q.

    4. Add a utility class `.tabular { font-variant-numeric: tabular-nums; }`. Pick the class name `.tabular` per CONTEXT.md Claude's Discretion (match existing site-common.css naming convention if a different convention is already in use — e.g., `.tabular-nums`). This utility will be applied to numeric `<td>` cells in later sweeps (WDG-06). Per finding R.

    5. Add `h1, h2, h3, [id] { scroll-margin-top: 4rem; }` so in-page anchor links and back-to-top jumps do not hide the heading behind sticky chrome.

    Group the new rules under a single comment banner like `/* === Cross-cutting a11y foundation (WDG-08, Phase 11 Sweep 1) === */` placed at a logical position (near top, after :root, before component sections — match site-common.css's existing organization). Reference 260513-wdg-FINDINGS.md in the banner for traceability.

    Do NOT edit site.css, admin.css, or any `site-*.css` theme fork. Do NOT remove existing rules. Per D-07 this sweep affects exactly one file.
