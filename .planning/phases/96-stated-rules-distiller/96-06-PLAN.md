ScryfallCardNameGrounder (DeckFlow.Web.Services.Scryfall) : ICardNameGrounder
  ctor deps: IScryfallCardResolver resolver, IMemoryCache cache
  TryGroundAsync(candidateName, ct):
    - normalize candidateName; short-circuit null/whitespace → CardGroundingResult(false, candidateName).
    - cache-get by normalized key; on miss call resolver.SearchPrintingFallbackCardAsync(candidateName, ct).
    - non-null ScryfallCard → CardGroundingResult(true, card.Name) (canonical rewrite); cache it.
    - null (404/ambiguous/none) or upstream exception → CardGroundingResult(false, candidateName); cache the negative too.
</interfaces>
