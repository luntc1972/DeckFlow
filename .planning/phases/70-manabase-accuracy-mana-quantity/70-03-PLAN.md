# 70-03 — MQ-03: Ramp-credit consistency (sim ↔ regression agree)

**Finding:** Audit #2 (High, two stacked bugs). Verified in code.
**Risk:** Med. **Blast radius:** the land TARGET (a verdict input) on ritual/Treasure/land-ramp
decks. Verdict-affecting → gated + baseline-diffed, same discipline as MQ-02.

## Problem
`RampAndDrawUnderThree` lowers the Karsten land target by −0.28 each (`ManabaseClassifier.cs:103-106`
counts every MV≤2 card where `IsRampOrDraw` is true). `IsRampOrDraw` (`:494-504`) matches any oracle
containing `"Add "`, a land-search, `"create a Treasure"`, or `"draw a card"`. Two defects:
1. **Sim never sees it.** One-shot mana (Dark Ritual, Rite of Flame, Treasure-makers) lowers the
   land target, but those cards are NOT added to `deck.Sources` (only rocks/dorks/MDFC-backs/granted
   are — `:120-125`, `AddPartialSources`). The castability sim therefore models no persistent access
   for that credited mana → "land count OK" / a softer verdict on ritual/Treasure decks.
2. **Over-credit in the regression itself.** Karsten's rampAndDraw term is for *repeatable* cheap
   ramp + true cantrips. Crediting **one-shot** rituals and Treasure-only makers at −0.28 each
   over-reduces the target independently of defect 1.

## Locked decisions
- **Narrow `IsRampOrDraw` to credit only repeatable ramp + true card-draw.** Credit:
  - a mana-producing **permanent** (artifact/creature/enchantment that taps for mana — the rock/dork
    already in `deck.Sources`, so the sim DOES see it), and
  - **land-ramp that puts a land onto the battlefield** ("search your library for a … land … onto
    the battlefield" — Cultivate/Rampant Growth — persistent access), and
  - **true card draw** ("draw a card/two cards" cantrips — Karsten's draw term; deck-thinning, no
    mana path needed).
  Drop from the credit:
  - **one-shot rituals** — `"Add "` on an **Instant or Sorcery** (non-permanent), and
  - **Treasure-only one-shots** — `"create a Treasure"` on a non-permanent with no other repeatable ramp.
- **Give the still-credited LAND-ramp a modeled mana path (defect 1).** A credited Cultivate-type
  card should add a deferred land to the sim's library/board so sim ↔ regression agree. This is the
  MQ-02-coupled half (reuses the ramp-deploy/online-turn machinery).
- **Verdict-affecting → ship behind a flag, default OFF**, decided after baseline diff. New flag
  `manabase.ramp-credit-v2` (seed FALSE, SQLite + Postgres). Flag-OFF path byte-identical to today.
  Read once in the caller, threaded as an explicit bool (same pattern as `useManaQuantity`). NOTE:
  the land-target compute (`ComputeTargetLands`/`KarstenManabase`) is pure today; thread the bool in,
  do not read an ambient flag inside Core.

## Side-Effects Report
- **Files (direct):** `DeckFlow.Core/Manabase/ManabaseClassifier.cs` (`IsRampOrDraw` predicate +
  the `:103` count gate; needs the card's type line / permanent-ness — already on `CardFact.TypeLine`),
  `DeckFlow.Core/Manabase/ManabaseAnalyzer.cs` (thread `bool rampCreditV2` into `ComputeTargetLands`
  and, for defect 1, into the deck handed to the simulator), `ManabaseModels.cs` (only if land-ramp
  needs a new source kind — prefer reusing `ManaSource`/`LibraryCard` with a deferred-land marker),
  `DeckFlow.Web/Services/Manabase/ManabaseAnalysisService.cs` (read the new flag, pass down),
  `DeckFlow.Web/Services/FeatureFlags/FeatureFlagStore.cs` (seed `manabase.ramp-credit-v2` FALSE).
- **Shared state / external:** none. **Contract:** `RampAndDrawUnderThree` value changes only on the
  flag-on path; report shape unchanged.
- **Interaction with MQ-02:** independent flags; both read in the service and threaded as bools. The
  land-target change (MQ-03) and the affordability change (MQ-02) are orthogonal; test both-on too.
- **Backward-compat:** flag-OFF must reproduce today's `RampAndDrawUnderThree`, target, and cast%
  exactly. The flag is the rollback.

## Steps
1. **Narrow the predicate (defect 2).** Split `IsRampOrDraw` into the credited categories above;
   gate the `"Add "`/`"create a Treasure"` branch on `IsType(TypeLine, "Instant"/"Sorcery") == false`
   (permanents only); land-search credited only when it reads "onto the battlefield"; keep draw.
   Behind `rampCreditV2` — when off, use the current broad predicate verbatim (byte-identical).
2. **Model the credited land-ramp in the sim (defect 1).** For each credited land-ramp card, add a
   deferred extra land to the simulated deck (online ~its MV+1 turn) so the sim sees the access the
   target credit assumes. Reuse `CastabilitySimulator`'s ramp/online-turn path; do not touch color
   counts. (If this proves large, ship step 1 alone behind the flag and split step 2 to 70-03b.)
3. **Wire the flag** (service reads `manabase.ramp-credit-v2`, threads bool; seed FALSE both DBs).
4. **Baseline diff** (extend the existing harness): a ritual deck (Dark Ritual / Jeska's Will), a
   Treasure deck, a land-ramp deck (Cultivate) — target + cast% + verdict OFF vs ON. Decide default.
