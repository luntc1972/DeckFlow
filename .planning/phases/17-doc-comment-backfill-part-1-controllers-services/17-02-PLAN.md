ScryfallCard is the ONLY declaration-detached case. FIX: DELETE the single blank line at line 39 so

Why DeckFlowDatabaseConnectionFactory was added: the ROADMAP SC1 verification originally used a
file-level anchored grep (`grep -L '<summary>'`), which passes any file that has at least one
`<summary>` anywhere. This file has three method-level summaries but NO summary on the
`public static class DeckFlowDatabaseConnectionFactory` declaration itself (line 7). The file-level
grep therefore reported it as "documented" while the TYPE was undocumented — exactly the gap
DOC-01 / D-01a forbid, and exactly the detachment class that the ScryfallCard blank line creates.
This is the SAME false-flag that would now hit the inheritdoc-only impls in the OTHER direction: a
file with NO `<summary>` string can still be fully documented via `<inheritdoc/>`. Both directions
are why the file-level grep is demoted to a non-blocking smoke check and the per-declaration awk
checker is authoritative.
