<objective>
Capture the two combo ranking fields the parser currently drops (`popularity`, `manaValueNeeded`) onto the `SpellbookCombo` record, and use them to priority-rank combos in the Deck Primer combo-reference block (PRM-08). Replaces the documented ranking stub that today sorts by produces-immediacy + piece count.

Purpose: The Deck Primer's combo reference should surface the most-played, cheapest-to-assemble combos first so the pasted prompt leads with the combos that matter. The parser already reads card names from `uses`; this plan adds the two top-level scalar ranking fields it ignores.
Output: `SpellbookCombo` gains `int? Popularity` and `int? ManaValueNeeded` (additive positional params, default null); `ParseVariants` populates them defensively; `BuildComboReferenceText` ranks popularity DESC then manaValueNeeded ASC then stable API order; regression tests cover parse + ranking.
</objective>
