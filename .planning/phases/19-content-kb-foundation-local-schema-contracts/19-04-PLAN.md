<objective>
Build the three remaining content stores in `DeckFlow.Web/Services/Content`: `WhisperSpendLedger` (one-row-per-call spend log + GetMonthlyTotalAsync + the cap-check stub for Phase 20 to wire, KB-05), `ContentHarvestRunStore` (local run-summary table parallel to — never shared with — v1.1 `harvest_runs`, KB-02), and `ContentSiteIndexStore` (the slim `content_site_index` — the ONLY shape destined for Render Postgres, KB-08). The cap-check is deliberately plain: no advisory lock, no SERIALIZABLE wrapper, no kill-switch (dropped with the local-harvester pivot). The slim index carries NO transcript/audio/spend data.

This plan applies four cross-AI review fixes: (#1) it now depends on `19-03` because `whisper_spend_ledger.video_id REFERENCES content_videos(id)` — the parent table must exist first; (#4) `GetMonthlyTotalAsync` sums APP-SIDE with `decimal` instead of `SQL SUM(cost_usd)` over TEXT, so decimals are exact; (#3) the site-index natural key is a normalized `natural_key_type + natural_key_value` pair giving a single UNIQUE and a single upsert conflict path that handles both youtube_video_id and rss_guid; (#5) artifact_path is validated on write (reject rooted/`..`) and the 3 tag columns use the locked JSON-array serialization from Plan 01.

Purpose: Complete the persistence foundation — spend tracking, run records, and the Render-bound slim index — so Phases 20/21 can wire ingestion + emit.
Output: 3 store interfaces + 3 store classes + 3 Web.Tests files.
</objective>

whisper_spend_ledger: id PK, video_id -> content_videos(id) ON DELETE CASCADE, seconds_billed INT NOT NULL,
  cost_usd DECIMAL(10,6) NOT NULL [SQLite: TEXT for exact decimal], month_key TEXT NOT NULL ('YYYY-MM'),
  created_utc TS NOT NULL DEFAULT now(); CREATE INDEX ix_spend_month ON whisper_spend_ledger(month_key)
content_harvest_runs: id PK, started_utc TS NOT NULL DEFAULT now(), completed_utc TS NULL,
  sources_processed INT NOT NULL DEFAULT 0, videos_processed INT NOT NULL DEFAULT 0,
  transcripts_fetched INT NOT NULL DEFAULT 0, whisper_calls INT NOT NULL DEFAULT 0,
  spend_usd DECIMAL(10,6) NOT NULL DEFAULT 0, aborted_reason TEXT NULL
content_site_index (Render-bound, Postgres parity): id PK, source TEXT NOT NULL, title TEXT NOT NULL,
  video_url TEXT NOT NULL, artifact_path TEXT NOT NULL (RELATIVE, validated on write),
  published_utc TS NULL, indexed_utc TS NOT NULL DEFAULT now(),
  archetype_tags TEXT NOT NULL DEFAULT '[]', bracket_tags TEXT NOT NULL DEFAULT '[]', card_category_tags TEXT NOT NULL DEFAULT '[]'  (JSON arrays, D-13),
  natural_key_type TEXT NOT NULL CHECK(IN 'youtube_channel','podcast_rss'), natural_key_value TEXT NOT NULL,
  UNIQUE(natural_key_type, natural_key_value)   -- single UNIQUE -> single upsert conflict path (REVIEW #3)
