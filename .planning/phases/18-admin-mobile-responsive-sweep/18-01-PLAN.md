dead `admin-feedback-*` rules out of `site-common.css` into `admin-common.css` with admin-token
substitutions, AND migration of the admin feedback success banner (`feedback-banner
feedback-banner--success`, currently stranded in `site-common.css` which admin never loads) into
`admin-common.css` `.admin-shell`-scoped with admin tokens.

moves into `admin-common.css`, EXCEPT the explicitly-enumerated admin-only global resets. A
deterministic selector-audit gate (Task 1 verify + acceptance) FAILS the task if any non-exempt
top-level `.admin-*`, `.detail-*`, `.type-badge`, or `dialog.admin-modal` selector survives.

wire Razor markup to them without re-deciding architecture. This is the interface-first plan —

switches `_AdminLayout.cshtml` to two `<link asp-append-version>` tags so BOTH new CSS files get
ASP.NET cache-busting fingerprints (the `@import` shim is retained inside `admin.css` as a
fallback but is no longer the load path — see Decision D-CACHE below).

Output: 3 admin CSS files (1 modified to shim, 2 new) + `site-common.css` with dead rules
removed + `_AdminLayout.cshtml` switched to two fingerprinted `<link>` tags.
