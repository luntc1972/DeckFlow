# 70-06 — Two-lens result header (Karsten source check + simulated cast rate)

**Why:** the manabase result buries the "what our number means vs a color-source counter"
distinction in help/`<details>` prose. MQ-02 makes our sim diverge further from a pure source
counter (it now models mana quantity too), so surface BOTH lenses at the top of the result:
- **Karsten source check** (left) — the validated colored-source target per color (✓ / ⚠ −N).
- **Simulated cast rate** (right) — our joint-game Monte-Carlo headline number.

Ships **with** the MQ-02 changes (same Phase 70 / `feature/manabase-accuracy` branch).

**Risk:** Low. **Blast radius:** the manabase result view only. **View-only — no Core change.**

## Design (locked from the approved mockup)
- Two-card band at the top of the `Result` section, above the existing `Lands … / Health chip` line.
- Left lens: one row per `report.ColorFindings` entry — `{Color}  {have} / {RequiredSources} need  ✓|⚠ −N`. **Display and decision use the SAME value (Codex HIGH):** show `ActualSources` as **`F1`** (matches the per-color table below — `18.0 / 17`, never `18 / 17` while actually 17.4); ✓ when `ActualSources >= RequiredSources` (raw double), else ⚠ with deficit `Math.Max(1, (int)Math.Ceiling(RequiredSources - ActualSources))` so an unmet color never shows `−0`. Caption: "validated colored-source target (Frank Karsten's math)".
- **Colorless deck (Codex LOW):** when `report.ColorFindings.Count == 0`, hide the left lens entirely (don't render an empty card).
- Right lens: the deck-level cast-rate headline + caption "joint mana + color, with mulligan, tapped-land timing, and ramp". Pill: **"avg across N tracked spells"** (NOT "non-land spells" — Codex MED: `Castability` excludes rocks/dorks and may omit unsupported cards, so `N = report.Castability.Count` is the tracked-row count, not the deck's non-land total).
- **Cast-rate number = mean `CastPercent` across `report.Castability` rows** (commander included — it is a normal row and order doesn't affect a mean). Labeled **"avg on-curve"**. `AvgOnCurve` returns 0 (and the right lens is hidden) when `Castability` is empty — no divide-by-zero.
- Desktop: 2-up grid; **mobile (<640px): stack vertically** (mockup verified, no overflow).
- **Right-lens gate = the SAME gate as the castability table (Codex NIT):** render it when `Model.ShowCastability && report.Castability.Count > 0` (do not infer mode from `Castability.Count` alone). Left lens renders whenever `ColorFindings` is non-empty.

## Steps
1. `ManabaseDisplay.AvgOnCurve(rows)` → `int` mean of `CastPercent` (0 when empty). Plus a small
   `KarstenMet(finding)` → (`bool met`, `int deficit`) helper for the ✓/⚠ marker.
2. Razor: add the `.manabase-twolens` block at the top of `Result`, left lens looping
   `report.ColorFindings`, right lens using `AvgOnCurve` + `report.Castability.Count`. Hide the right
   lens when `report.Castability` is empty.

   no per-theme hardcoded colors.
