== Filter-ordering fact (for executor + 66-06) ==
FeatureFlagGate is an IAsyncActionFilter; ASP.NET antiforgery validation runs BEFORE action filters. So for a
mutating POST sibling of a DISABLED tool: a token-LESS POST returns 400 (antiforgery, before the gate) and a
token-VALID POST returns 404 (the gate). Both are blocked, which is correct. Any test proving the 404 GATE
fires on a POST must submit a valid antiforgery token (see 66-06). Do NOT reorder the gate vs antiforgery
pipeline to 'simplify' this — the ordering is intended security behaviour.
