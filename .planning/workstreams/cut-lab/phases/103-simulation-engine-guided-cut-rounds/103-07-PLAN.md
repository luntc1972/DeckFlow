<objective>
Build the async decision endpoint that powers the D-09 loop AND its no-JS fallback: a shared `CutLabDecisionApplier` applies accept/reject/defer/restore to the state (appending/removing decision records; Pool stays immutable per HIGH-1); the JSON endpoint `POST /api/cut-lab/decide` and the form action `POST /cut-lab/decide` both call it. The form action instead re-renders the full page through `ProcessAsync` (which already recomputes proposal + deltas server-side per HIGH-4).

Purpose: This is the CUT-03 transport with a real no-JS fallback (HIGH-5). It reuses the round engine (CUT-01), simulation service (SIM-01/CUT-02), shared analysis context (HIGH-2), floor rules (FLOOR-02), and caches (D-10).
Output: Decision applier, request/response DTOs, `CutLabApiController`, the `CutLabController.Decide` fallback, and tests.
</objective>
