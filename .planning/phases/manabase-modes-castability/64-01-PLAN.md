5. **Castability helper** (KarstenManabase.cs): `public static CardCastability ComputeCastability(int deckSize, int totalLands, double nonLandSourceWeight, SpellRequirement spell, IReadOnlyDictionary<ManaColor,int> colorSources, int onCurveTurn, bool onPlay = true)`:
   - `T = onCurveTurn` (= `spell.ManaValue` unless a cost reducer shifted it earlier — Task 10), clamped `>= max(1, totalPips)`. `draws = CardsSeenByTurn(T, onPlay)`. Record both `ManaValue = spell.ManaValue` and `OnCurveTurn = T` on the result.
   - **Weighted ramp pool** (Codex HIGH #1 — do NOT use a raw non-land count; the source model weights dorks 0.5 / rocks 0.75): caller passes `nonLandSourceWeight = sum of s.Weight for deck.Sources where !s.IsLand`. `pMana`: `T <= 2` → `AtLeast(deckSize, totalLands, draws, T)` (ramp not online by turn 1–2); `T >= 3` → `AtLeast(deckSize, totalLands + (int)Math.Floor(nonLandSourceWeight), draws, T)`.
   - **Defensive clamps on every hypergeometric input** (Codex LOW — `LogChoose` throws if `n > 512`): `population = Math.Min(deckSize, 512)`; `draws = Math.Min(draws, population)`; each `successes = Math.Clamp(value, 0, population)`.
   - `pColor`: product over each color in `spell.Pips` (value>0, non-colorless) of `AtLeast(population, clamp(colorSources[color]), draws, pips)`. Missing color → 0. **Empty `Pips` (colorless spell) → empty product → `pColor = 1.0`** so castability = pMana.
   - `cast = pMana * pColor`; `CastPercent = Math.Clamp((int)Math.Round(cast * 100), 0, 100)`.
   - `LimitingFactor`: compare `pMana` to `minColorP`; if within 0.03 → `"both"`; else `"mana"` or `"color:" + weakestColor`. Colorless spell (no colors) → always `"mana"`.

   > **Independence caveat (Codex HIGH #2 — decided, not a blocker):** `pMana × pColor` treats mana-quantity and color-access as independent, but the same physical sources feed both, so the product is an **approximate ranking metric, biased slightly optimistic** (most for gold / multi-pip costs where a few duals dominate both). v1 ships it explicitly labeled "estimate" in the UI (Wave 2 caveat) and uses it for **ordering**, not as a precise probability. Joint-probability modeling is a deferred refinement. Tests must include shared-source cases (UU, WU, colorless off a Sol-Ring-heavy deck) and assert ordering + a documented tolerance, not exact equality.
