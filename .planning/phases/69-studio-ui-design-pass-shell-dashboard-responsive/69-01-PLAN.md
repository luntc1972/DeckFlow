    override Bootstrap's explicit light `background-color` declarations. Without this bridge, OS dark
    mode produces dark studio chrome on a WHITE Bootstrap body/tables/cards — the exact inconsistency
    the checker flagged.)

    PART A — re-point the studio color tokens to the dark column (spacing/type tokens NOT redeclared):
    `--studio-bg: #0f172a`, `--studio-surface: #1e293b`, `--studio-input: #1e293b`,

    query:
    1. Remap the THREE live Bootstrap theme vars on `:root` — `--bs-body-bg: var(--studio-bg)`,
       `--bs-body-color: var(--studio-text)`, `--bs-table-bg: var(--studio-surface)` — and remap the
       two utility RGBs so `.bg-light`/`.bg-white` go dark: `--bs-light-rgb: 30, 41, 59` and
       `--bs-white-rgb: 30, 41, 59` (the RGB of `#1e293b`).
    2. Add EXPLICIT element overrides for the surfaces Bootstrap 5.1 hardcodes light AND that Studio
       pages actually use. Confirmed against bootstrap.min.css v5.1.0:
       - base `.table` (ALL 12 Studio data tables use `table table-sm table-hover`; `.table-light` is
         on `<thead>` only): Bootstrap sets the tbody text via DIRECT `color:#212529` (NOT a var) and
         the hover/stripe/active overlays as `rgba(0,0,0,.05/.075/.1)` which DARKEN on a dark bg, so
         this MUST be overridden or rows render ~1.2:1 dark-on-dark. Add:
         `.table{ color: var(--studio-text); border-color: var(--studio-border);
         --bs-table-color: var(--studio-text); --bs-table-striped-color: var(--studio-text);
         --bs-table-active-color: var(--studio-text); --bs-table-hover-color: var(--studio-text);
         --bs-table-striped-bg: rgba(255,255,255,.05); --bs-table-active-bg: rgba(255,255,255,.10);

         now-dark body, so the cell BACKGROUND is already handled by the `--bs-body-bg` remap — it is
         the TEXT + overlays that need this rule.)
       - `.table-light` (thead): in 5.1 it sets text via DIRECT `color:#000` (NOT `--bs-table-color`),

         `color: var(--studio-text)`, `border-color: var(--studio-border)`. ADDITIONALLY override the
