<objective>
Add the AUTO-02 quality signal as a swappable Core seam and surface each distilled video's
clip count on DistillResult so the Studio host (Plan 02/03) can decide auto-approval.

Purpose: Isolate the "is this distill good enough to auto-approve" decision behind an interface
(D-02) so a future composite signal replaces only this class, and expose the per-video clip count
the decision needs (D-01) without changing the distill schema, provider, or model (SC4).
Output: `IAutoApproveSignal` + `ClipCountAutoApproveSignal`, a `DistilledVideoResult` record (the
public per-video result DTO), a new `DistillResult.DistilledVideos` field populated by the
orchestrator, plus xUnit coverage.

Naming note (Codex MEDIUM): the public per-video result DTO is named `DistilledVideoResult` —
deliberately NOT `DistilledVideoOutcome` — to avoid a near-homonym collision with the EXISTING
private orchestrator accumulator record `DistillVideoOutcome`. Keep the two names distinct
(`DistilledVideoResult` = public DTO; `DistillVideoOutcome` = private internal accumulator).
</objective>
