<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| creator-sourced content (cached decks, whitelist) -> assembled artifact text | Exemplar/whitelist card names come from a cached Archidekt crawl (creator-controlled corpus) and flow into prompt text a user will paste into an LLM. |
| user-submitted request strings -> assembled artifact text | CreatorStyleRequest string fields (deck name/slug/deck source) are untrusted input echoed into or driving the artifact. |
| DeckFlow.Web -> ICardGroundingGuard (Scryfall) | Every referenced card name is validated through the Phase 98 guard before it can appear in the artifact. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-99-03-01 | Spoofing | hallucinated/illegal/stale card name shipped in the critique artifact | mitigate | Single batched ICardGroundingGuard.ValidateAllAsync over the DISTINCT union of all referenced names; only Accepted canonical names reach the result/text; non-accepted (rejected or upstream-unavailable) excluded and GroundingDegraded flagged (fail-closed). Do not bypass the guard for "obviously real" cached cards (cache staleness/bans are the exact class the guard catches). |
| T-99-03-02 | Tampering | prompt-injection via crafted deck/creator free-text flowing unescaped into artifact text | mitigate | Length-cap + newline-collapse any user-controlled string before interpolation (MaxCompanionNameLength precedent); card names are guard-canonicalized; treat CreatorStyleRequest fields as unsanitized. |
| T-99-03-03 | Information Disclosure | silently shipping a shrunken card set when Scryfall hiccups | mitigate | GroundingDegraded flag + a visible caveat line in the artifact disclose any withheld cards rather than silently degrading. |
| T-99-03-04 | Denial of Service | large union of card names -> guard batch cost | mitigate | Whitelist is capped at 25 (existing); exemplars capped at 3 decks; union is de-duplicated before the single batched guard call (75-card chunking handled inside the guard). No per-card HTTP loop. |
| T-99-03-SC | Tampering | package installs | accept | No new packages introduced; no supply-chain surface. |
</threat_model>
