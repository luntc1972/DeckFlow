## STEP 5 — Distill on the subscription claude CLI ($0)

Distill needs **TWO** env vars in the dotnet.exe process:
- `DECKFLOW_LLM_PROVIDER=claude` — selects the subscription backend (skips the OpenAI cap/pricing; spend=$0).
- `DECKFLOW_LLM_CLI_COMMAND` — the JSON-array CLI spec the service shells out to. Required; the classifier (first LLM call) throws without it. For Windows-dotnet.exe-from-WSL the documented value re-enters WSL to run `claude`:
  `["wsl.exe","/home/clunt/.local/bin/claude","-p","{instruction}","--output-format","json","--allowedTools",""]`

**Option A — both inline from WSL bash (try first):**
```bash
DECKFLOW_LLM_PROVIDER=claude \
DECKFLOW_LLM_CLI_COMMAND='["wsl.exe","/home/clunt/.local/bin/claude","-p","{instruction}","--output-format","json","--allowedTools",""]' \
"/mnt/c/Program Files/dotnet/dotnet.exe" run --project DeckFlow.CLI -- distill --db artifacts/uat-content-kb.db --limit 12
```
(Inline `VAR=val cmd` populates the child env WSL interop forwards to dotnet.exe — your earlier `PROVIDER=claude` proved it crosses.)

**Option B — fallback (.bat) if A doesn't take:**
```bash
printf '@echo off\r\nset DECKFLOW_LLM_PROVIDER=claude\r\nset DECKFLOW_LLM_CLI_COMMAND=["wsl.exe","/home/clunt/.local/bin/claude","-p","{instruction}","--output-format","json","--allowedTools",""]\r\n"C:\\Program Files\\dotnet\\dotnet.exe" run --project DeckFlow.CLI -- distill --db artifacts\\uat-content-kb.db --limit 12\r\n' > scripts/_distill-snail.bat
cmd.exe /c scripts\\_distill-snail.bat
```
Delete `scripts/_distill-snail.bat` after (throwaway, not committed).

> The 12 videos currently marked `failed` (from the no-CLI_COMMAND run) auto-retry — the pending-distill query treats `failed` as re-distillable. No reset needed.

**PASS gates:**
- Batch summary log shows `videos_distilled=… videos_filtered=… spend_usd=0.000000` (subscription = $0).
- At least one sampled junk video lands status `filtered` (classifier "drop").
- Distilled survivors get real clips.

Verify counts + a filtered sample + clip timestamps:

## STEP 6 — Operator publish + /content-kb browse

**Architecture:** the web `/content-kb` does NOT read `uat-content-kb.db` directly. The pipeline is:
CLI distill → `content-index-export` (JSON seed) → web seed-loader (on startup) → `content-site-index.db` → Admin publish (toggles `is_visible`) → `/content-kb`.
So Step 6 exercises the same **deploy seed** that ships to prod. The CLI-distilled rows land `is_visible=false` (hidden) until an operator publishes.

> Two separate SQLite files: distill writes `artifacts/uat-content-kb.db` (full corpus); the web site reads `artifacts/content-site-index.db` (slim index, dev-only — prod uses Postgres). The corpus-reset did NOT touch `content-site-index.db`, so it still holds the OLD 392-row corpus until cleared in 6b.

**6a. Export the new seed** (⚠️ overwrites the tracked `content-kb/seed/index-seed.json` — this becomes the new-corpus deploy seed; back up first):
```bash
cp content-kb/seed/index-seed.json content-kb/seed/index-seed.PRE-37.5.bak.json
"/mnt/c/Program Files/dotnet/dotnet.exe" run --project DeckFlow.CLI -- content-index-export --db artifacts/uat-content-kb.db
python3 -c "import json;print('seed rows:',len(json.load(open('content-kb/seed/index-seed.json'))))"
```
PASS gate: `seed rows: 7`.

**6b. Clear the stale web site-index** (back up + delete; web recreates empty + reseeds on startup):
```bash
cp artifacts/content-site-index.db artifacts/content-site-index.PRE-37.5.bak.db
rm artifacts/content-site-index.db
```

**6c. Start the web app** (you start servers). On startup the seed-loader loads the 7 rows (hidden) into a fresh `content-site-index.db`:
```bash

```
Watch the startup log for `Content KB seed load complete: 7 rows.`

**6d.** Ensure `content.kb.enabled` is ON (`/Admin/Flags`). Then `/Admin` (BasicAuth) → KB Curation → publish the 7 survivors.

**6e.** Browse `/content-kb`:

**Bonus (Deck Primer tile visual-verify, while app is up):** home page → Deck Primer tile sits in the **Build** group; Deck-tool tab strip → **Build** dropdown lists Deck Primer; opening `/deck-primer` highlights **Build**, not Analyze.
