      using var deadline = new CancellationTokenSource(ShutdownDrainCeiling);
      var batch = new List<RequestMetricEvent>(BatchSize);
      try

          while (_buffer.Reader.TryRead(out var evt))
          {
              batch.Add(evt);
              if (batch.Count >= BatchSize)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Request thread -> RequestMetricsBuffer.Enqueue | Synchronous write; no I/O; protected from blocking by DropOldest |
| RequestMetricsBuffer -> RequestMetricsFlusher | Async hand-off via Channel.Reader; flusher owns the slow path |
| RequestMetricsFlusher -> IRequestMetricsStore | DI scope per flush — store handles its own connection lifetime |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06 | Denial of Service (silent metric loss) | RequestMetricsFlusher.ExecuteAsync | mitigate | Per-tick try/catch wraps `FlushBatchAsync` so a transient PG failure logs `Analytics.Flusher.TickFailure` and the loop continues. Without this, one exception kills the BackgroundService and the buffer fills + drops everything (RESEARCH Pitfall 6). |
| T-08-07 | Information Disclosure (drop-counter race) | RequestMetricsBuffer._droppedCount | mitigate | `Interlocked.Increment` + `Interlocked.Exchange` ensure no lost increments under contention. `ConsumeDropCount` atomically reads-and-resets. |
| T-08-08 | Denial of Service (hot-path block) | RequestMetricsBuffer.Enqueue | mitigate | `BoundedChannelFullMode.DropOldest` guarantees `TryWrite` never blocks/awaits. Capacity 10000 sized for ~640KB worst case (RESEARCH "Project Constraints" — Render Starter 512MB cap). |
| T-08-09 | Denial of Service (DI cycle) | RequestMetricsFlusher ctor graph | mitigate | Flusher takes `IServiceProvider` (not `IRequestMetricsStore` directly) per D-14. Wave 3 mandates D-15 startup smoke-test. |
| T-08-10 | Repudiation (drop log spam) | MaybeLogDrops | mitigate | One WARN per ~60s, never per-drop; spam-resistant (D-10). |
