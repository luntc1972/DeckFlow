## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → /api/content-kb/* | Untrusted query string `q` reaches the search endpoints |
| localStorage → hidden form fields | Client-controlled selection enters the request (re-validated server-side in Plans 01/02) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-32-07 | Tampering | localStorage poisoning | mitigate | Server never trusts localStorage directly; only form-submitted values reach the DTO, and Plan 01 resolves ids against published rows / caps pins at 3 |
| T-32-08 | Information Disclosure | Search endpoints leaking hidden entries | mitigate | /api/content-kb/entries+creators read only visible (published) rows via GetPublishedRowsAsync; no hidden/admin data exposed |
| T-32-09 | Denial of Service | Unbounded typeahead result sets | mitigate | Both endpoints Take(10); attachTypeahead debounces and requires min chars |
| T-32-10 | Cross-Site Scripting | User-rendered chip titles / tray labels | mitigate | Razor HTML-encodes @entry.Title/@creator by default; TS sets textContent (not innerHTML) for dynamic chips/tray items |
| T-32-SC | Tampering | npm/pip/cargo installs | accept | No package installs; phase installs zero external packages (RESEARCH §Package Legitimacy Audit: not applicable) |
</threat_model>
