## Defects found during UAT (fixed mid-pilot — Codex impl / Claude review)

1. **Deck Primer not on the home hub** (pre-existing gap, user-reported) — moved the tool into the
   **Build** group: added a `Home.cshtml` Build-group tile + relocated the `_DeckToolTabs.cshtml`
   nav link and its active-group flag. Commit `14353aa`.
2. **`corpus-reset --connection-string` rejected the `postgres://` URL form** Npgsql can't parse —
   the web's `NormalizePostgresConnectionString` wasn't reachable from the CLI. Extracted to
   `DeckFlow.Core/Storage/PostgresConnectionStringNormalizer`; web factory delegates; corpus-reset
   normalizes before connecting. +5 Core tests, web regression 7/7. Commit `d2ee743`.
3. **Postgres `'filtered'` migration built `DROP CONSTRAINT ""`** (`42601`) — lookup filtered on
   `LIKE '%status IN%'` but Postgres renders the CHECK as `= ANY (ARRAY[...])`, and
   `Convert.ToString(null)` returns `""` (defeating the null guard). Fixed: `LIKE '%distilled%'` +
   `IsNullOrWhiteSpace` guard + helper coerces empty→null. Commit `d28ef10`.
