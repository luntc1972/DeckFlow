## Summary

This video argues MTG's current all-one-off-set era feels rushed, giving no plane time to breathe, with bouncing disconnected storylines and no mechanical iteration since each plane gets only one set. But three-set blocks (Return to Ravnica, Theros, Tarkir) weren't better—each had a weak set (Dragon's Maze, Born of the Gods, Fate Reforged) that felt like a story stepping-stone rather than a cohesive world, and later block sets sold worse and strained Limited. The proposed middle ground: bring back two-set blocks alongside one-offs. Two full-sized sets use an establish-then-complicate framework—set one builds a world, set two dramatically changes it—telling a place's story better, extending a setting's lifespan without stagnation, while each remains a standalone Limited format. Missed opportunities since 2023: Murders at Karlov Manor (Ravnica Remastered should've been an original setup set featuring guilds), Lorwyn Eclipsed (deserved a Lorwyn+Shadowmoor pairing), and especially Bloomburrow—a slam-dunk spring-then-autumn 'prepare for winter' progression. The author critiques Mark Rosewater's claim that lower sequel-set sales prove players want gaps between visits, calling it a flawed reading of data. Treating every set as a disposable 'hat set' signals creative lack of conviction in the worlds being made.

## Key Clips

- The last time we had a 'block' of two or more consecutive sets on the same plane was about three years ago, with every set since being a one-off set. There hasn't been a multi-set block in a brand new plane since Ixalan block concluded more than eight years ago.
- Having every set be a new plane, particularly with five or more sets per year, makes things feel rushed, makes it feel like there's no time to breathe and to become immersed in a particular world. Storylines are bouncing and disconnected, since we can never stop and watch how a particular plane changes.
- Three set blocks don't really represent a better vision of the game, just one with a different set of problems. The middle or third set was often a little awkward—Dragon's Maze, Born of the Gods, Fate Reforged—feeling more like a stepping stone for story purposes than a fully thought out landscape of its own.
- The biggest reason I like two-set blocks is that they're able to tell the story of a place much better. Set one establishes a setting, and then a later set complicates that setting, introducing new elements and showcasing a dramatically changed version of it. This is a wonderfully blunt form of storytelling.
- I truly cannot think of a more obvious slam dunk of a two-set block than Bloomburrow. The first set set in late spring introduces this vibrant world and all its creature types, then the second set takes place in autumn with more urgency and darkness as the creatures 'prepare for winter.' Create a setting, and then complicate it.
- Murders at Karlov Manor: choosing Ravnica, the plane about guilds, with only a feeble little 'oh yeah, this plane exists' reprints set a month before is just a very odd choice. Instead of Ravnica Remastered, drop an original new Ravnica set two months in advance to establish the characters and feature the guilds.
- In a blog post, Mark Rosewater used the metric that sales are almost always lower for subsequent sets in a block to extrapolate that players 'don't want to stay in the same world for consecutive sets.' The issue is, those aren't things that sales data can tell you. There are a ton of reasons subsequent sets might sell worse.
- When every set is a one off—when OTJ is treated the same as Bloomburrow which is treated the same as Spiderman which is treated the same as Lorwyn—it feels like the people making the game have no faith in the worlds they're creating. The harder version of being bold is actually committing to a vision.
