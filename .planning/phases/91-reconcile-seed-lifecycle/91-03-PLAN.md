<objective>
Ship the D-02 legacy backfill: a host-agnostic `SeedManagedBackfill` that classifies every
`seed_managed IS NULL` row by CURRENT `index-seed.json` membership (present -> true, absent -> false),
idempotently and without ever crashing host startup, wired at both the web (prod-pointed - where the
~70 prod-only rows live) and Studio (local) startups. Mirrors the P89 `ContentBodyHashBackfill`
dual-host design exactly.

CRITICAL SAFETY GATE (Codex-HIGH): the backfill classifies ONLY when the seed was genuinely
present-and-parsed (SeedIndexReadResult.SeedAvailable == true). When the seed is absent / unreadable /
parse-failed on this run, the backfill MUST skip entirely (zero writes, rows stay NULL). If it instead
classified all NULL rows `false` against a missing seed, a later CORRECT seed could never repair them
(the setter is null-only), permanently corrupting the safety marker. A valid EMPTY seed is still allowed
to classify (all-absent -> false is correct then).

Purpose: So no reconcile run ever sees an unclassified row, and the ~70 prod-only rows become
distinguishable from seed-owned rows (the SYNC-17 safety guarantee) - without ever mis-stamping legacy
rows off a seed that simply was not readable this boot.
Output: the backfill class + a per-host seed-membership seam (availability-aware) + dual-host wiring.
</objective>
