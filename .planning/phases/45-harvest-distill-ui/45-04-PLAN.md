|----------|-------------|

| Page cap-raise input → SessionCapOverride | Operator-supplied numeric value raises the effective spend ceiling for the session |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-45-10 | Tampering | Silent re-distill of already-distilled videos | mitigate | Already-distilled videos enter `distillIds` only when BOTH the re-distill checkbox and the secondary "Yes, I understand" checkbox are checked (Pitfall 5); the dry-run button stays disabled otherwise. Verified in checkpoint step 6. |
| T-45-11 | Elevation of privilege | Unbounded LLM spend | mitigate | Live distill requires a successful dry-run AND a reviewed-spend confirmation checkbox AND a clear cap gate; projected-vs-cap is checked before Stage B enables, and the orchestrator independently enforces WouldExceedCapAsync. |
| T-45-12 | Elevation of privilege | Session cap raised to extreme value | accept | The raise writes only the in-memory SessionCapOverride (D-03); it resets to env/default on restart (verified in checkpoint step 7). Cost risk bounded to one operator session; numeric input is validated non-negative. |
| T-45-13 | Spoofing / repudiation | Metered-provider distill shown as success | mitigate | When isSubscriptionProvider=false the orchestrator aborts with Success=false + AbortedReason; the page surfaces AbortedReason in a danger alert and never renders the success card for an aborted run. |
| T-45-14 | Information disclosure | Spend/cap/provider in logs | mitigate | The page displays cap/spend to the operator (intended) but logs no connection string, provider value, or ledger key; checkpoint step 8 verifies no secret leakage. |
| T-45-SC | Tampering | npm/pip/cargo installs | accept | No package installs; no new NuGet (CLAUDE.md). |
