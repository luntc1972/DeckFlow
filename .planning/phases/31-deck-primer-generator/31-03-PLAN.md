| Boundary | Description |
|----------|-------------|
| decklist text / deck URL -> service | Untrusted card data + URL; parsed by Moxfield/Archidekt parsers; passed as literal data, never as instructions |
| upstream JSON (Spellbook/EdhTop16) -> prompt | Untrusted third-party text rendered into the prompt body |
| service -> AI prompt | Assembled server-side; combo ground-truth block structurally fenced from the speculative ask (D-2) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-07 | Tampering | Prompt-injection framing via decklist / deck name / upstream combo text | mitigate | All user + upstream text emitted as literal card/combo data under fenced headings; the speculative ask is structurally separated from the ground-truth block (D-2) so injected "instructions" in combo text cannot masquerade as the speculative directive |
| T-31-08 | Denial of Service | Pathological combo / near-combo volume bloating the prompt | mitigate | AlmostIncludedCombos capped at 15 (existing MaxAlmostIncluded); selected-section count bounded by the 31-entry catalog; downstream Gemini cap (31-04) trims |
| T-31-09 | Information Disclosure | EdhTop16 / Spellbook upstream failure surfacing a stack trace | mitigate | FindCombosAsync null contract + try/catch graceful degradation (disclosure line, omit blocks); never throw on upstream failure |
| T-31-10 | Spoofing | Crafted commander name yielding unexpected category rows | mitigate | GetCategoryRowsForCommanderAsync is a parameterized read via the dialect abstraction (no string SQL); empty result omits the block |
