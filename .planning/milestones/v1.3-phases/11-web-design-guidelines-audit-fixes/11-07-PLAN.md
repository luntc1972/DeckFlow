<objective>
Land Sweep 7 of the WDG audit: sweep-apply `autocomplete="url" inputmode="url"` + ellipsis placeholder suffix to every `<input type="url">`, and `autocomplete="off"` to every user-paste `<textarea>`, across the affected views.

Purpose: URL inputs without `autocomplete="url"` + `inputmode="url"` give mobile users the wrong soft-keyboard layout. User-paste textareas without `autocomplete="off"` trigger password-manager modals on long pastes (deck text, JSON blobs). WDG-09 sweep harmonizes these affordances across all affected forms.

Output: Eight Razor views updated with attribute additions at the file:line sites flagged in FINDINGS.md findings T + U.
</objective>
