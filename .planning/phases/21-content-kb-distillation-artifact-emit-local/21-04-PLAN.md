|----------|-------------|

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-21-09 | Tampering | Out-of-vocab tags reaching content_tags / slim index | mitigate | ContentTagVocabulary.IsValid filter; drop + WARN; never persist (E2/D-04) |
| T-21-10 | Denial of service (cost) | Runaway LLM spend in the batch loop | mitigate | WouldExceedCapAsync before each video; sequential processing keeps cap accurate; over-cap hard-stop + aborted_reason (SC5) |
| T-21-11 | Tampering | Non-idempotent re-run double-writes | mitigate | Skip-completed (artifact+index probe); ClearDistillOutput before re-distill; index row written LAST (Q2) |

| T-21-13 | Information disclosure | OPENAI_API_KEY in logs | mitigate | Service reads key from env, never logs it (Plan 01); orchestrator logs no secrets |
