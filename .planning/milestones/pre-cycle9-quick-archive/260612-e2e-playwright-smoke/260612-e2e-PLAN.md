# Quick Task 260612-e2e: Playwright E2E smoke suite

## Why (user-approved)

The site has unit (Vitest jsdom) + controller (xUnit) tests but ZERO whole-site
UI/E2E coverage. Every bug this session (dead Primer copy, no-scroll, mobile busy
lockup, dead admin filter + single-click confirms from Phase 37) needed the real
rendered page + real compiled JS + a click to catch. Add a minimal Playwright smoke.

User-approved: add `@playwright/test` (chromium), routes + key interactions, wire CI now.

### Task 3 — smoke.spec.ts (routes × viewports)
For EACH of the 15 routes, in BOTH projects:
- Collect console errors via `page.on('console', m => m.type()==='error')` and pageerrors.
- `const resp = await page.goto(route); expect(resp?.ok()).toBeTruthy();`
- Assert no console errors / no page errors (allow an empty-list assertion).
- Assert no horizontal overflow: `expect(await page.evaluate(() => document.documentElement.scrollWidth <= window.innerWidth + 1)).toBeTruthy()`.
- Keep it data-light: do NOT submit forms or call upstream APIs.

### Task 4 — scripts.spec.ts (per-page script presence — the regression catcher)
- A table mapping route → required script filename substrings (from the map above; include
  the layout trio for every route).
- For each route, assert every required script tag exists:
  `expect(await page.locator('script[src*="primer-selection"]').count()).toBeGreaterThan(0)` etc.
- This is the cheapest, highest-value check — it directly catches a dropped <script>
  include (the Phase 37 bug).

### Task 5 — interactions.spec.ts (safe, data-light + conditional)
- Primer (/deck-primer): assert primer-selection.js present; assert the bracket select
  `[data-primer-bracket]` and at least one `[data-primer-section-checkbox]` are visible.
  (Copy/scroll need a generated result + upstream — covered by Vitest; do NOT generate here.)
- Admin Content KB (/Admin/ContentKb?visibilityFilter=all, uses httpCredentials):
  - assert content-kb-admin.js + admin-modal.js + kb-entry-filter.js present.
  - assert `#kb-filter-search` exists; type 'zzzznomatch' and assert no console error fired
    (wiring present). If `#kb-entries-table tbody tr` count > 1, also assert visible rows
    decreased (filter narrows).
