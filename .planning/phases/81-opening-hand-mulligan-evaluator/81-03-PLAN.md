test asserts the OFF page equals the ON page minus the card). Mirror all of it for the mulligan lens card. There
is NO hidden-field JSON round-trip and NO zip on `/manabase` (the report is recomputed each analyze — verified),
so this plan is simpler than Phase-79's Step-3: no round-trip plumbing, no zip entry, no deserialize hardening.

Purpose: MULLIGAN-01 requires the keepable metric + color/curve read on the page (not just the artifact);
MULLIGAN-02 requires the London PROCESS (keep-size + representative openers) visible on the page; MULLIGAN-06
requires the page byte-identical when the flag is OFF. The card prose reuses Plan 81-02's honest framing: a BAND
not a false-precision %, the keep criterion stated narrowly, an EVALUATION consistency signal — never keep/mull
advice — and, because the sim runs per spell, the per-opener on-curve read names the tracked play it belongs to
(TrackedSpellName + TrackedOnCurveTurn from Plan 81-01), never a generic claim.
Output: the ViewModel flag, the controller mapping, a display band helper, the flag-guarded lens card + CSS, an
extended render byte-identity test, and a desktop+mobile Playwright live-UX smoke.
