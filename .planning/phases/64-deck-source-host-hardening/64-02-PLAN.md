<objective>
Adopt the `DeckSourceHost` helper (from 64-01) at all four deck-source call sites that currently
use substring host matching, and fix the Moxfield→Commander-Spellbook fallback to always forward a
reconstructed canonical URL. Then lock the new behavior with adoption/regression tests at each site.

The four sites (from RESEARCH "Spoofable-Site Inventory"):
- S1: `DeckEntryLoader.cs:121` — `uri.Host.Contains("moxfield.com", OrdinalIgnoreCase)` → `DeckSourceHost.IsMoxfield(uri)`
- S2: `DeckEntryLoader.cs:127` — `uri.Host.Contains("archidekt.com", OrdinalIgnoreCase)` → `DeckSourceHost.IsArchidekt(uri)`
- S3/SC2: `MoxfieldApiDeckImporter.cs:105-107` — drop the `originalUrl.Contains(...)` conditional; always `$"https://moxfield.com/decks/{deckId}"`
- S4: `PacketArtifactStore.cs:99-100` — `uri.Host.Contains(...) || uri.Host.Contains(...)` → `DeckSourceHost.IsMoxfield(uri) || DeckSourceHost.IsArchidekt(uri)`

Purpose: Eliminate the spoofable substring host-trust everywhere (SEC-01), stop forwarding the
user-submitted URL on the Spellbook fallback (SEC-02), and add per-site regression coverage (SEC-03).
Output: 3 source files migrated to the helper + 3 test files extended with spoof/canonical cases.
</objective>
