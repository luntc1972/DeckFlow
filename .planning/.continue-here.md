## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Verified the worktree, claimed the commit | Ran build + 2270 tests + e2e after committing and reported green. The commits were syntactically broken (functions spliced into the wrong function body, `<form>` closed by `</section>`); every tool had read the working tree, which was correct. Only a later `git diff` exposed it. | blocking | After every commit, run `git diff HEAD --stat \| wc -l` and require 0 before running or reporting any verification. |
| Zero-context hunk staging | Used `git diff -U0` + `git apply --cached --unidiff-zero` to split one worktree into per-defect commits. Hunks applied at wrong offsets and silently corrupted `deck-sync.ts` and `DeckSync.cshtml`. Required resetting six commits. | blocking | Split commits by whole file. If a file genuinely spans two concerns, either commit them together and say so, or reorder the source so the regions are not adjacent — never rely on `-U0` offsets. |
| E2E spec forcing a flag to a guessed resting state | The Batch G spec enabled Deck Sync, then forced it to `false` in `afterEach` on the assumption it ships off. It ships **on**. Flag state persists in the dev database, so one run silently broke 5 tests across 3 files on every later run. | blocking | Any spec toggling a tool flag must capture the prior value (`getToolEnabled`) in `beforeEach` and restore *that* in `afterEach`. Never hardcode the restore value. Note `bracket-smoke.spec.ts` still has the hardcoded pattern — correct today, same latent trap. |
| Inferring flag state from a 404 | Concluded "Deck Sync ships off" from a 404, which was actually the wrong URL — the route is `/sync`, not `/deck-sync`. | Full e2e suite dirties tracked files | A full `playwright test` run rewrites ~51 tracked PNGs under `.planning/ui-design/cut-lab/screenshots/` and writes untracked ones under `cycle13/`. A careless `git add .planning/` swept 6 into a commit. | advisory | After any full e2e run: `git checkout -- .planning/ui-design/`, and never `git add` a directory — add explicit paths. |
