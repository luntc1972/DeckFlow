<objective>
Add a `corpus-reset` CLI command that purges the Content KB corpus on BOTH SQLite and Postgres
(REBUILD-01) and fix the three-site `[00:00]` clip-timestamp defect (REBUILD-03) so future distills
carry real, spot-checkable, mid-video clip timestamps.

Purpose: The old corpus is gate-condemned junk; it must be cleared (local + prod) before the
high-signal re-harvest. The clip-timestamp fix is a prerequisite for the re-harvest — without it
every clip renders `[00:00]` and the new all-zero guard would block every distill.
Output: A reset command that handles local SQLite AND prod Postgres (with testable store-level
purge methods) + a timestamped transcript fetcher (with a pure, unit-tested formatting helper) +
a stricter clips prompt + an all-zero clip rejection guard ON THE LIVE distill path, with Wave-0
unit tests.
