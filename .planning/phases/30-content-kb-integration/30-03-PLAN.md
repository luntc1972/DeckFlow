<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| harvested clip text -> AI prompt | Curated KB clip text is interpolated into the prompt sent to ChatGPT/Claude/Gemini |
| relevance service -> packet pipeline | Clips cross from the (plan 02) service into prompt + zip + result |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-08 | Tampering | Prompt injection via harvested clip text ("ignore previous instructions") in the Expert Context block | accept | KB is admin-curated before publish (IsVisible gate); clips are block-quoted and labeled as third-party context, not instructions; the AI session is the user's own paste target (no server-side agent acts on the output). Residual risk accepted; surfaced for operator awareness. |
| T-30-09 | Denial of Service | Expert Context block pushing Gemini prompt past the paste cap | mitigate | Gemini variant budget guard skips injection when total length > 50000 chars (Pitfall 5) |
| T-30-10 | Information Disclosure | Clips persisted into the downloadable zip | accept | Clips are already public KB content (published, IsVisible=true); no secret material; zip is the user's own session artifact |
| T-30-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs; existing packages only (no new dependencies per CLAUDE.md) |
</threat_model>
