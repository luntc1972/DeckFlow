<objective>
Add a read-only pre-flip git-coverage audit (D-11): for every approved + visible prod `content_site_index` row, check whether its body `.md` exists in the local git `content-kb` tree (what will become `/app` after deploy), and report the rows whose body is MISSING. This makes the SYNC-07 flip precondition — "every visible row's body is actually in git" — explicit and observable BEFORE the operator flips `sync.directpush-gitbody` ON.

Purpose: STATE.md records ~70/106 prod rows may be body-only on the `/data` overlay and not in the approved git seed. The moment the flag flips ON, such a row's detail page goes 404. This audit surfaces the count/list so the operator can git-commit missing bodies first. It is READ-ONLY reporting this phase — it does NOT delete or reconcile (that is Phase 91's reconciler).
Output: a Studio read-only audit service + interface + unit tests; no prod writes, no deletes.
</objective>
