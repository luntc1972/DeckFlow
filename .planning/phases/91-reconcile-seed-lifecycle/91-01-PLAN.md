<objective>
Ship the SYNC-17 foundation contract: the `seed_managed` marker column on `content_site_index`
(nullable, dialect-guarded, additive), a null-only idempotent backfill write method, and a single
shared Core reader for `index-seed.json` natural-key membership that later plans (D-02 backfill,
reconcile orchestrator) reuse.

Purpose: Establish the row-level seed-ownership marker that gates all seed-driven removal (the
Codex-HIGH hard prereq). Nullable (`NULL` = unclassified, distinct from `false` = classified
prod-owned) so the D-02 backfill can be re-run safely.
Output: `ContentSiteIndexRow.SeedManaged`, the column across all store SQL, `SetSeedManagedIfNullAsync`,
and `SeedIndexFileReader` (returning a 3-outcome `SeedIndexReadResult`).
</objective>

New Core reader (DeckFlow.Core/Content/SeedIndexFileReader.cs):
  // Three-outcome result. SeedAvailable=true means the seed file was present AND parsed
  // (NaturalKeys may legitimately be EMPTY). SeedAvailable=false means absent / unreadable /
  // parse-failed and NaturalKeys is empty-but-MEANINGLESS - callers that gate destructive or
  // classification behavior MUST treat SeedAvailable=false as "do nothing", never as "empty set".
  public sealed record SeedIndexReadResult(bool SeedAvailable, IReadOnlySet<string> NaturalKeys);

  // Primary API - distinguishes present-and-parsed (incl. valid empty) from unavailable.
  public static SeedIndexReadResult Read(string seedFilePath);

  // Convenience for read-only dry-run callers that do not gate on availability (returns
  // Read(...).NaturalKeys; empty when unavailable). Do NOT use this on the backfill/classify path.
  public static IReadOnlySet<string> ReadNaturalKeys(string seedFilePath);
