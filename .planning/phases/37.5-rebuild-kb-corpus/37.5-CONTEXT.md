<decisions>
## Decisions (locked)

- **Reset the corpus.** Purge all current KB content — `content_videos`, `content_transcripts`, `content_summaries`, `content_clips`, `content_tags`, `content_site_index` (and distill-status/spend-ledger as appropriate) — to empty, in BOTH local and prod (Postgres). Destructive; coordinate the prod reset. (The old corpus is the gate-condemned generic/intro-only content.)
- **Start with salubrious-snail only.** Re-harvest just the Salubrious Snail channel first as the pilot of the new quality bar; other creators are a later pass once the pipeline + filter are proven.
- **Quality filter = HYBRID.** (1) Distill-time LLM classifier: each video is classified as *deck-advice / deckbuilding-philosophy* vs *drop* (trivia like "is X a draw spell?", news/set-commentary, meta/format-philosophy with no actionable deckbuilding content, pure intro/announcement). Non-advice videos are NOT indexed. (2) Manual admin confirm: the operator reviews the survivors in the admin curation grid and publishes only the genuinely useful ones. LLM removes the obvious junk; the human is the final gate.
- **Fix the clip-extraction defect (`[00:00]` root cause).** Confirmed: the distiller returns clips with NULL timestamps and `CommandRunners.cs:1255` stores `TimestampSeconds ?? 0` (0 = unknown sentinel), so EVERY clip renders `[00:00]`. Fix:
  - Feed the distiller the transcript WITH timestamps (YouTube captions are timestamped) so it can cite real times.
  - Change the clip-extraction distill prompt to require a real `timestamp` per clip (mm:ss / seconds), pointing at the moment the advice is given, and to select substantive mid-video advice moments — not the opening.
  - Validate: reject/flag a distill whose clips are all timestamp 0 (so the defect can't silently recur).
- **Goal of the rebuilt corpus:** a smaller, high-signal set where each published entry is genuine deck advice/philosophy with correctly-timestamped clips, browsable via `/content-kb` and copyable via the existing entry "Copy artifact" button.

### Claude's Discretion (decide at plan/impl)

- Whether the classifier is a new distill step or a gate inside the existing distill flow.
- How many clips per video + min/max — but they MUST have real distinct timestamps.
- Prod reset mechanism (truncate vs re-provision) + sequencing with the local rebuild.
