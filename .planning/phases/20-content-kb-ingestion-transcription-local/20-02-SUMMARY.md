## What Was Built

- Added `ITranscriptSource` with non-null `TranscriptFetchResult`, `TranscriptOutcome`, factory helpers, Whisper billing fields, authoritative `knownDuration`, and verb-supplied `monthKey`.
- Added YoutubeExplode 6.6.0 to `DeckFlow.Core.csproj` only; no package lockfile was generated.

- Added `IYouTubeAudioSource`, `AudioDownloadResult`, and `YouTubeAudioSource` for audio-only stream download to temp files with size, filename, best-effort non-authoritative duration, and `IDisposable` cleanup.
- Preserved D-11 purity: these services do not depend on content stores, spend ledgers, DB writes, or persistence APIs.

## Deviations / Notes

- Added focused tests for `TranscriptFetchResult` and `YouTubeAudioSource` in addition to the two test classes explicitly named in the plan; they are non-network tests and cover the new contracts.
- `YouTubeCaptionResult` includes `CaptionTrackKind` in addition to the requested boolean `IsAutoGenerated` so the harvest verb can log `caption_track_kind` directly.
- `YouTubeAudioSource` creates a unique subdirectory under `Path.GetTempPath()/deckflow-audio/` and writes `audio.<ext>` inside it. This keeps cleanup precise: `Dispose()` deletes the file and only that source-created subdirectory.
- YoutubeExplode 6.6.0 exposes audio stream size but not stream duration on `IStreamInfo`; `DurationSeconds` is therefore currently `0` from the audio source and remains explicitly non-authoritative.
- A first full-Core test attempt was started concurrently with the solution build and hit a transient SourceLink obj-file lock. It was rerun sequentially and passed.
