<decisions_made>

- `SeoPaths` refactored from a separate `Indexable` list + `NonToolPages` set into one `Pages` array of `SeoPage` records (`Path`, `IsIndexable`, `IsTool`); `Indexable` and `Tools` are derived. Each page is declared exactly once, so sitemap, structured data and canonical URL cannot drift apart.
- `/content-kb` → `IsTool=true, IsIndexable=false`. Flag-gated internal tool: keeps tool metadata (share bar, structured data), stays out of search discovery.

- Help gating is **deliberately asymmetric**: index gated by attribute, topics gated per-topic, so a tool's help page disappears with its tool independently of `tool.help.enabled`. Finding 1 is the hole this leaves.
