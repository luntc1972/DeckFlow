# 70-03 — MQ-03: Ramp-credit consistency (sim ↔ regression agree)

**Finding:** Audit #2 (High, two stacked bugs). Verified in code.
**Risk:** Med. **Blast radius:** the land TARGET (a verdict input) on ritual/Treasure/land-ramp
decks. Verdict-affecting → gated + baseline-diffed, same discipline as MQ-02.

**SCOPE (split per Codex review):** this plan = **defect 2 only** — narrow the credit (classifier +
flag + baseline). **Defect 1** (model the still-credited land-ramp in the sim) is structurally a
larger simulator change and moves to a separate **70-03b-PLAN.md** (see "Deferred to 70-03b" below).
70-03 ships the regression-credit fix; 70-03b later closes the sim↔regression gap.

## Problem
`RampAndDrawUnderThree` lowers the Karsten land target by −0.28 each (`ManabaseClassifier.cs:103-106`
counts every MV≤2 card where `IsRampOrDraw` is true). `IsRampOrDraw` (`:494-504`) matches any oracle
containing `"Add "`, a land-search, `"create a Treasure"`, or `"draw a card"`. Two defects:
1. **Sim never sees it.** One-shot mana (Dark Ritual, Rite of Flame, Treasure-makers) lowers the
   land target, but those cards are NOT added to `deck.Sources` (only rocks/dorks/MDFC-backs/granted
   are — `:120-125`, `AddPartialSources`). The castability sim therefore models no persistent access
   for that credited mana → "land count OK" / a softer verdict on ritual/Treasure decks.
2. **Over-credit in the regression itself.** Karsten's rampAndDraw term is for *repeatable* cheap
   ramp + true cantrips. Crediting **one-shot** rituals and Treasure-only makers at −0.28 each
   over-reduces the target independently of defect 1.

## Locked decisions
- **Narrow `IsRampOrDraw` with POSITIVE keep-rules (Codex HIGH — a "non-Instant/Sorcery" filter is
  too weak; it keeps one-shot-ETB-Treasure permanents and incidental "Add" text).** Credit a card
  iff it matches one of:
  - **Mana permanent** — `IsRockOrDork(card)` / `ProducesMana(card)` is true (the rock/dork already
    in `deck.Sources`; a real repeatable tap-for-mana source). This reuses the existing predicate, so
    the credited set == the persistent-source set.
  - **Land-ramp onto the battlefield** — oracle contains a land search AND `"onto the battlefield"`
    (Cultivate/Rampant Growth/Nature's Lore — persistent access; land-search-to-HAND does NOT count).
  - **True card draw** — `"draw a card" / "draw two cards"` (Karsten's draw term; deck-thinning).
  Everything else loses the −0.28 credit, which **drops one-shot rituals** (`"Add"` on an
  Instant/Sorcery) AND **drops Treasure-based credit entirely in v2** (a repeatable Treasure engine is
  not reliably distinguishable from `OracleText` alone — encode it later if needed, don't guess now).
- **Verdict-affecting → ship behind a flag, default OFF**, decided after baseline diff. New flag
  `manabase.ramp-credit-v2` (seed FALSE, SQLite + Postgres). Flag-OFF path uses the CURRENT broad
  `IsRampOrDraw` verbatim → byte-identical `RampAndDrawUnderThree`/target/cast%.
- **Flag must reach CLASSIFICATION, not just the analyzer (Codex HIGH).** `RampAndDrawUnderThree` is
  computed in `ManabaseClassifier.Classify`, which the service runs BEFORE `ManabaseAnalyzer.Analyze`.
  So the service reads `manabase.ramp-credit-v2` once **before classification** and threads the bool
  into `ResolveAndClassifyAsync` → `ManabaseClassifier.Classify`. Core stays pure (no ambient flag
  read), same discipline as `useManaQuantity`.
- **MQ-03 does NOT touch the simulator or color counts.** Pure land-target (regression) change.

## Deferred to 70-03b (defect 1 — sim ↔ regression agreement)
The still-credited land-ramp (Cultivate) lowers the target but the sim models no extra land. Closing
that gap is its own plan because (Codex BLOCKER) it must NOT be a free extra `LibraryCard` — that
land would be drawable in the opener and inflate mulligan keeps before the ramp spell is even cast.
70-03b will model it **on the ramp-spell deploy event** (when the spell is drawn + played, enqueue a
deferred land that comes online ~MV+1), reusing the ramp/online-turn path, and **quantity-only /
colorless** (Codex MED — `CardFact` has no structured fetched-land color, and MQ-03 must not change
color counts). Out of scope for 70-03.

## Side-Effects Report
- **Files (direct):** `DeckFlow.Core/Manabase/ManabaseClassifier.cs` — `IsRampOrDraw` becomes the
  positive keep-rule predicate; `Classify` takes a new `bool rampCreditV2` param threaded to the
  `:103` count gate (off → call the current broad predicate verbatim). `DeckFlow.Web/Services/Manabase/
  ManabaseAnalysisService.cs` — read `manabase.ramp-credit-v2` (via `Snapshot().TryGetValue`, fail-safe
  OFF, same as MQ-02) BEFORE `ResolveAndClassifyAsync`, thread the bool into classification.
  `DeckFlow.Web/Services/FeatureFlags/FeatureFlagStore.cs` — seed `manabase.ramp-credit-v2` FALSE
  (Postgres + SQLite).
- **No simulator/analyzer change** (that's 70-03b). **No Core model change** (no new field).
- **Other `Classify` callers:** CLI / tests / harness call `ManabaseClassifier.Classify` — give the
  new param a default `false` so existing callers stay on today's behavior (byte-identical).
- **Shared state / external:** none. **Contract:** `RampAndDrawUnderThree` changes only flag-on;
  report shape unchanged. **Interaction with MQ-02:** independent flags, both read in the service;
  orthogonal (target vs affordability) — test both-on too.
- **Backward-compat:** flag-OFF must reproduce today's `RampAndDrawUnderThree`/target/cast% exactly.

## Steps
1. **Positive keep-rule predicate.** Add `IsRepeatableRampOrDraw(card)` (mana-permanent via
   `IsRockOrDork`/`ProducesMana` ∪ land-search-to-battlefield ∪ true draw). Keep the existing broad
   `IsRampOrDraw` for the off path.
2. **Thread the flag through classification.** `Classify(..., bool rampCreditV2 = false)`; the
   `:103` gate uses `IsRepeatableRampOrDraw` when on, else `IsRampOrDraw`.
3. **Wire the flag** in the service (read once before classify via `Snapshot().TryGetValue`, fail-safe
   off; thread into `ResolveAndClassifyAsync`/`Classify`); seed `manabase.ramp-credit-v2` FALSE both DBs.
4. **Baseline diff** (extend the harness): a ritual deck (Dark Ritual / Jeska's Will), a Treasure
   deck, a land-ramp deck (Cultivate) — `RampAndDrawUnderThree` + target + verdict OFF vs ON. Decide default.
