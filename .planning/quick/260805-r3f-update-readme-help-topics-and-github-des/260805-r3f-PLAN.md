<the_judgment_rule>

**This is the part that must not be got wrong. Read it before touching a single line.**

Every occurrence of an old name is exactly one of two things:

- **TILE / NAV / PAGE REFERENCE → rename.** The sentence is about the tool, the page, or the tile.
  Examples: "the Mana Base tool", "open Deck History", "[Deck Sync](/sync)", a bullet in a list of
  tools, a page heading, a help topic title, "the Bracket Check page (`/bracket`)".
- **DOMAIN TERM → leave byte-for-byte alone.** The sentence is about the game concept or the data
  artifact, not the product surface. Examples: "your deck's mana base", "improve the mana base",
  "the history file", "the history JSON", "a deck history snapshot" used as a data concept, "the
  *mana base*, not the curve".

**Worked example, README line 3** — both kinds in one sentence:

> "It provides a deterministic **mana-base analyzer** and a local bracket classifier; ... a
> **Deck History** tool for versioning a deck"

`mana-base analyzer` is descriptive prose about what the thing does → KEEP. `Deck History tool` is
a reference to the tile → RENAME to `Deck Version Tracker`.

**Casing is the main signal but is NOT decisive.** Judge from what the sentence is about. A Title
Case occurrence can still be a domain term, and a lowercase one can still be a page reference.

**"Deck History" is the highest-risk name.** The tile is now "Deck Version Tracker", but *deck
history* remains the correct term for the JSON file / snapshot / version-log concept the tool reads
and writes. A blanket rename produces nonsense like "upload your Deck Version Tracker file". When
the sentence is about the **file or the data**, keep "history". When it is about the **tool or the
page**, rename.

**Second-highest risk: `manabase.md`.** Most of its "mana base" occurrences are the game concept.
Only the page-level ones (frontmatter title, the H1, "The Mana Base page (`/manabase`)") rename.
The button label "**Analyze Mana Base**" at `manabase.md:48` is UI chrome quoted verbatim — check
it against the actual rendered button before changing it; if the button still says "Analyze Mana
Base", keep the doc accurate and log it as KEPT.

</the_judgment_rule>
