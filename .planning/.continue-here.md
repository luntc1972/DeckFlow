# BLOCKING CONSTRAINTS — Read Before Anything Else

> These were discovered through failure during Phase 999.1 execution and apply to ANY future phase that uses Claude Code `isolation="worktree"` executors on this repo. Acknowledge each before spawning the next phase's wave 1.

- [ ] CONSTRAINT: WSL `node_modules` symlinks block `worktree.cleanup-wave` — Each agent worktree contains a symlink at `DeckFlow.Web/node_modules` → main tree's `node_modules`. `.gitignore` pattern `node_modules/` (trailing slash) does NOT match the symlink-as-file, so `git status` reports it as untracked. The `gsd-sdk query worktree.cleanup-wave` helper aborts with `worktree_dirty` / `?? DeckFlow.Web/node_modules`. Structural mitigation: BEFORE invoking `worktree.cleanup-wave`, iterate the wave's manifest worktree paths and `rm "$WT/DeckFlow.Web/node_modules"` for each symlink (test with `[ -L … ]`). Symlinks regenerate on next MSBuild run.
- [ ] CONSTRAINT: Claude Code worktree locking blocks `git worktree remove` — Worktrees spawned with `isolation="worktree"` are marked locked (`lock reason: claude agent agent-…`); cleanup-wave's first removal attempt fails with `cannot remove a locked working tree`. Structural mitigation: when cleanup blocks with `worktree_remove_failed` + `locked`, run `git worktree unlock <path>` for each worktree in the manifest, drop already-merged entries from the manifest JSON, then re-invoke `worktree.cleanup-wave`.
- [ ] CONSTRAINT: WSL has no native `dotnet` — Build gate must invoke `dotnet.exe` from Windows host SDK at `/mnt/c/Program Files/dotnet/dotnet.exe`. Literal `dotnet build ...` fails with `No such file or directory`. CLAUDE.md additionally pins: VSTest unreliable in WSL → rely on `dotnet build` clean + manual harness or push-and-watch CI. Structural mitigation: build gate uses `dotnet.exe build DeckFlow.sln -c Release`; skip post-merge **test** gate in WSL (treat `TEST_EXIT=0` build-only).
- [ ] CONSTRAINT: Run `cleanup-wave` from PRIMARY worktree, never from inside an agent worktree — Last completed background agent leaves orchestrator CWD pinned to its worktree path. Cleanup must run from primary or merges target wrong tree. Structural mitigation: before `worktree.cleanup-wave`, `cd $(git worktree list --porcelain | awk '/^worktree /{print substr($0,10); exit}')` and verify branch matches orchestrator branch (currently `v1.3`).

**Do not proceed until all boxes are checked.**
