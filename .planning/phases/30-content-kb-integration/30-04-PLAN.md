| result clips -> rendered HTML | Clip text (Source/Title/Excerpt) rendered into the result page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-11 | Tampering | D-08 preview input (previewCommander/previewBracket) | mitigate | previewBracket validated against ContentTagVocabulary.Brackets allowlist (invalid -> null); previewCommander normalized to a single line before use (V5 input validation) |
| T-30-12 | Cross-Site Scripting | Clip text + admin preview echo rendered in Razor | mitigate | Razor HTML-encodes interpolated values by default; VideoUrl rendered as href only (no raw HTML); no @Html.Raw on clip fields |
| T-30-13 | Elevation of Privilege | Admin preview endpoint | mitigate | Index lives under the /Admin branch already gated by BasicAuthMiddleware; preview is a read-only GET (no state change, no CSRF surface) |
| T-30-SC | Tampering | npm/pip/cargo installs | mitigate | No package installs; existing packages only (no new dependencies per CLAUDE.md) |
</threat_model>
