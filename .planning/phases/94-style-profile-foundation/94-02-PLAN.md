<locked_overrides>
Two forks were resolved with the user AFTER CONTEXT.md — these OVERRIDE any conflicting CONTEXT/PATTERNS note:

1. The three section columns are plain `TEXT NULL` on BOTH dialects (NOT `jsonb`). This matches
   `content_site_index`'s established JSON-blob convention and avoids the Npgsql cast-trap class of bug
   (same family as the F-51-PG-01 timestamptz 42883 lesson). Do NOT use `jsonb`.
2. `updated_utc` is the ONE genuinely dialect-split timestamp column: `TIMESTAMPTZ` on Postgres,
   `TEXT` on SQLite. It is ONLY ever written (upsert) or SELECTed — never used in a WHERE/filter — so
   the timestamptz-vs-text cast trap does not apply to reads. GetBySlugAsync filters on `slug` (TEXT both dialects).
</locked_overrides>
