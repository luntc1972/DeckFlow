## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-01 | Tampering / Spoofing | `UseRewriter` AddRedirect targets in `Program.cs` | mitigate | Redirect targets are HARDCODED literal absolute paths (`deck-analysis`, `deck-comparison`, `cedh-meta-gap`). NO user input, query string, or regex backreference is interpolated into the replacement. Open-redirect is structurally impossible here. |
| T-12-02 | Information disclosure | 301 Location header on HTTPS deployment | mitigate | Pipeline order invariant: `UseForwardedHeaders` MUST run before `UseRewriter` (verified at acceptance — line-number ordering check) so the 301 `Location` honors `X-Forwarded-Proto: https` and the browser is not downgraded to plaintext. Same invariant already protects `UseHttpsRedirection` per `CLAUDE.md`. |
| T-12-03 | Denial of service | regex evaluation cost on UseRewriter rules | accept | 9 anchored, literal-prefix regex rules (`^chatgpt-…$`). No backtracking-prone patterns. Per-request cost is constant. |
</threat_model>
