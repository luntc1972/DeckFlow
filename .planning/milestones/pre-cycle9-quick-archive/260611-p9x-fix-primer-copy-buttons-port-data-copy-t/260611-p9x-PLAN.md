# Quick Task 260611-p9x: Fix Primer copy buttons

## Problem

`DeckPrimer.cshtml` (line 298) loads ONLY `primer-selection.js`. That module
(`primer-selection.ts`) has zero copy-button logic. The `[data-copy-target]`
click handler that powers Copy buttons lives in `deck-sync.ts:598`
(`attachActionButtons`) and only runs on pages loading `deck-sync.js`. Result:
the two Primer Copy buttons (`#primer-output`, `#primer-chat-title`) never get
a click listener → dead.

Canonical reference impl: `DeckFlow.Web/wwwroot/ts/deck-sync.ts:557-613`
(`copyElementValue`, `setTemporaryButtonText`, `announceToScreenReader`, the
`[data-copy-target]` loop inside `attachActionButtons`).

## Tasks

### Task 1 — Port copy wiring into primer-selection.ts

**read_first:**
- `DeckFlow.Web/wwwroot/ts/primer-selection.ts` (current module — IIFE, exposes `win.DeckFlow.initPrimerSelection`, DOMContentLoaded hook)
- `DeckFlow.Web/wwwroot/ts/deck-sync.ts` lines 557-613 (reference copy impl)
- `DeckFlow.Web/Views/Deck/DeckPrimer.cshtml` lines 257, 284 (the two `data-copy-target` buttons: `primer-chat-title`, `primer-output`)

**action:**
- Add three helpers to the `primer-selection.ts` IIFE, ported from `deck-sync.ts`:
  - `copyElementValue(targetId: string): Promise<void>` — reads `.value` for
    `HTMLTextAreaElement`/`HTMLInputElement` else `textContent`, early-returns on
    empty, calls `navigator.clipboard.writeText(text)`.
  - `setTemporaryButtonText(button, text, durationMs = 1800)` — swaps button
    label to `Copied` / `Copy failed`, toggles `is-copied`/`is-copy-failed`
    classes, restores after timeout. Store original in `dataset.copyOriginalText`.
  - `announceToScreenReader(message)` — writes to `[data-copy-announcer]` if
    present (no-op on Primer page; keep for parity).
- Add `attachPrimerCopyButtons(): void` that binds a `click` listener to every
  `[data-copy-target]` element: on click read `dataset.copyTarget`, await
  `copyElementValue`, then `setTemporaryButtonText(button, 'Copied')`; on throw
  `setTemporaryButtonText(button, 'Copy failed')`.
- Invoke `attachPrimerCopyButtons()` inside `initPrimerSelection()`. It MUST run
  even when the bracket form / section checkboxes are absent — do NOT place it
  after the existing `if (!form || !bracketSelect) return;` or
  `sectionCheckboxes.length === 0` early-returns. Call it at the very top of
  `initPrimerSelection`, before those guards, so copy works regardless of form
  state.
- Expose the copy entry point for tests: set
  `win.DeckFlow.attachPrimerCopyButtons = attachPrimerCopyButtons;` alongside the
  existing `initPrimerSelection` assignment.
- Preserve LF line endings, 2-space TS indent, existing strict-mode style.

**acceptance_criteria:**
- `primer-selection.ts` contains `navigator.clipboard.writeText(`
- `primer-selection.ts` contains `querySelectorAll<HTMLElement>('[data-copy-target]')`
- `primer-selection.ts` contains `win.DeckFlow.attachPrimerCopyButtons =`
- `attachPrimerCopyButtons()` is called inside `initPrimerSelection` BEFORE the
  `if (!form || !bracketSelect)` guard
- `cd DeckFlow.Web && npx tsc -p tsconfig.json --noEmit` exits 0
