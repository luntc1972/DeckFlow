# Phase 999.6 Plan 02: BasicAuth Flaky Stabilization Summary

**One-liner:** Closed the `BasicAuthMiddlewareTests.CorrectCredentials_InvokesNext` flaky fact by extracting a shared `EnvScope` helper and serializing the two env-mutating test classes (`BasicAuthMiddlewareTests` + `Security/AdminBruteForceTrackerStoreTests`) into a single xUnit `[CollectionDefinition(DisableParallelization=true)]` — eliminating the cross-class `FEEDBACK_ADMIN_USER`/`FEEDBACK_ADMIN_PASSWORD` process-global race confirmed via `/gsd-debug` hypothesis triage.

**F-ENV-COLLECTION** (D-14 default, the only deterministic option per Codex R2 MEDIUM #2 for the empirically-confirmed cross-class race). NOT F-ENV-CLEAR-EAGER (ruled out by debug verdict because eager-clear-then-set is not atomic with respect to concurrent mutators). ## Debug Verdict (verbatim from .planning/debug/999.6-basicauth-flaky.md)

> **`FLAKY_DUE_TO_CROSS_CLASS_ENV_VAR_RACE`**
>
> Not a stale test. Not a real production bug. The middleware is correct; the test infrastructure has a global-state coupling between two test classes that the default xUnit parallelism exposes.

Hypothesis results:
- **H1 (cross-class env-var race between `BasicAuthMiddlewareTests` and `Security/AdminBruteForceTrackerStoreTests`):** **PASS**. Two distinct inline `EnvScope` implementations mutate the same process-global `FEEDBACK_ADMIN_USER`/`FEEDBACK_ADMIN_PASSWORD`; xUnit default parallel-by-class scheduling interleaves their `Set`/`Dispose` calls.
- **H2 (env-var cache in middleware):** **FALSIFIED**. `BasicAuthMiddleware.InvokeAsync` reads `Environment.GetEnvironmentVariable` fresh on every invocation (lines 53-54). No construction-time cache. Production code is correct.
- **H3 (`IMemoryCache`/store retention across facts):** **FALSIFIED**. Each fact creates its own `AdminBruteForceTrackerStore` via `CreateStore(out _)` with `Guid.NewGuid():N` path. No store reuse.
- **H4 (intra-class fact-order state bleed):** **FALSIFIED**. Filter-isolation passes 5/5; intra-class ordering would have leaked the same race under filter-isolation.
