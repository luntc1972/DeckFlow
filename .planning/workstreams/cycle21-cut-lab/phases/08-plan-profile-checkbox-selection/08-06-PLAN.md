## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request → Cut Lab page / decide API → EDHREC fetch | A user request now triggers outbound requests to a third party, once per checked theme |
| EDHREC response → affinity map → proposal order | Third-party data influences engine output on every request path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-06-01 | Denial of Service | Server-side request amplification — one user request fanning out to many EDHREC requests | mitigate | Before any request, intersect client session slugs with the fetched known-theme list, deduplicate case-insensitively and impose a hard maximum. Checked plus necessary unchecked memberships are then fetched sequentially; the service memoizes successful results. A crafted-session JSON test asserts the bound and exact unique slugs. |
| T-08-06-02 | Denial of Service | A slow or hanging EDHREC stalling the Cut Lab page and the decide API | mitigate | The `edhrec` Polly pipeline's 10s per-attempt timeout and 2-retry cap bound each fetch, and every failure path returns immediately with the strategy-only map. The ambient `CancellationToken` is threaded to every await. |
| T-08-06-03 | Tampering | Client-supplied theme slugs driving outbound requests (server-side request forgery shape) | mitigate | Slugs are validated against `^[a-z0-9-]+$` inside `EdhrecCommanderThemeService` before any request, and the base address is a fixed constant, so a slug cannot change the host or escape the path. |
| T-08-06-04 | Information Disclosure | The commander name being sent to a third party | accept | Only the commander name, already public card data, leaves the app. No user identifier, deck contents, or session data is transmitted. This matches the existing EDHREC usage already shipped for the manabase baseline. |
| T-08-06-05 | Tampering | Divergent affinity between the page path and the AJAX patch path | mitigate | All three paths call the same factory with the same inputs; a single resolution point removes the class of defect that produced Phase 3's WARNING-severity AJAX gap. |
| T-08-06-SC | Tampering | npm / NuGet installs | mitigate | No packages added. Any new package stops the plan pending explicit user approval. |
</threat_model>
