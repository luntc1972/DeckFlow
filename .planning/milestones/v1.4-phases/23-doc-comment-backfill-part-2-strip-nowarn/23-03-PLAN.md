      public IActionResult Home()

  AFTER (comment above attribute; attribute line byte-identical):

MEMBER-COVERAGE RULE (mandatory — CS1591 fires on EVERY public declaration, not just the type or
action methods): Document EVERY public declaration in the allowed files, including public classes,
records, interfaces, enums, enum members, CONSTRUCTORS, methods (every public action AND every public
helper), properties, and positional record parameters — not just the controller type and its action
methods. Co-located public types (a nested enum, a `*ViewModel` declared in the same file, a request
record) and public constructors all trip CS1591 too. The per-file site counts in 23-RESEARCH.md are
compiler-derived (the compiler counts members), so each listed count already reflects the full
per-member inventory; documenting only the type + action methods will leave warnings behind and fail
the 23-05 gate.

STRICT-PARAM RULE (mandatory — prevents new CS1573 leaking out of 23-04's owned set): If ANY
`<param>` is present on a member, EVERY parameter on that member must have a matching `<param>` tag.
A partial `<param>` set spawns a fresh CS1573 the moment the suppressors flip. Either document ALL
params on a member or NONE (a bare `<summary>` with no `<param>` is fine for CS1591); never a partial
set.
</conventions>
