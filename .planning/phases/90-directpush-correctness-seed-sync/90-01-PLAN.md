<objective>
Register the `sync.directpush-gitbody` web-DB feature flag (seeded OFF, catalog description) and flip the Content-KB body-serving path so that, when the flag is ON, a body resolves EXCLUSIVELY from the git `/app` tree — dropping the `/data`-SFTP-first overlay fallback (SYNC-07, D-01). With the flag OFF (default), serving behavior is byte-identical to today, so this ships with zero live risk.

Purpose: SYNC-07 kills the M1 unreachable-body and M3 `/app`-shadows-`/data` failure classes by making git the only body source, matching the git-single-source-of-truth stance Publish already follows. The flag is the authoritative home (D-04) that Studio's DirectPush path will read in later plans.
Output: the registered/seeded flag, a flag-gated resolver, and xUnit tests proving flag-OFF preserves git-then-overlay and flag-ON is git-only.
</objective>
