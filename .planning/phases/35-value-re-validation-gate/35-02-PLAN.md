<rubric>
<!-- Locked from spike README + 35-CONTEXT KBV-03. Score each AI ANSWER 1-5 per dimension. -->
1. Specificity   — concrete, deck-specific advice vs generic deckbuilding-101 maxims.
2. Creator-voice — does the answer reflect distinctive creator heuristics (not just generic voice)?
3. Novel signal  — anything the baseline answer did NOT already produce.
4. Actionability — clear, correct cuts/adds the deck owner can apply.
Quality-regression check — does the with-context clip set inject noise / a misleading frame
  (e.g. a foreign-commander or glass-cannon clip that misfits the deck)? Note any regression per deck.

DECISION RULE (KBV-04, locked): VALIDATED iff with-context shows clear lift on >=2 rubric dimensions in
>=3 of the 5 decks AND no quality regression on any deck. Otherwise MARGINAL.
</rubric>
