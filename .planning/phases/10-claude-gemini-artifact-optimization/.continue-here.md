# Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| disabled-submitter cancels form submit | Setting `button.disabled = true` synchronously inside a click handler on a `type="submit"` button cancels the form submit. The browser sees disabled at submit-time and skips the default action. | advisory | Use a `dataset` attribute for in-flight state, not `disabled`. The first click goes through; subsequent clicks within the debounce window hit the dataset guard via `event.preventDefault()`. See commit `d54da44`. |
| last-instruction-wins skips early format directives | When an instruction-tuned model (especially Gemini) reads `## OUTPUT FORMAT` mid-prompt followed by long data sections (e.g., DECKLIST, REFERENCE DATA at the end), the JSON wrapper directive can be ignored — the model follows the LAST instruction it read. | advisory | Append a strong, explicit JSON-mandate as the absolute final line of the prompt. See `ChatGptJsonTextFormatterService.GeminiJsonMandate` const + commit `a1ab008`. |
| Codex grep guards miss timing semantics | The original code-review of the debounce only checked timeout values + grep patterns — it didn't simulate click→submit timing. Resulted in a regression that broke the download path entirely. | advisory | When dispatching code review for browser-DOM logic, include a "timing trace" prompt: walk through each event in order and identify what state the DOM is in at each transition. |
